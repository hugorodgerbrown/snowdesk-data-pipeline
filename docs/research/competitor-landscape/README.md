# Competitor landscape — quarterly meta-analysis

A quarterly read across the weekly scans in
[`docs/competitors.md`](../../competitors.md): not what each competitor did,
but where the category as a whole is heading. Each edition is a dated file in
this directory and covers the scans since the previous edition.

Most recent: [2026-11-12](2026-11-12.md) — covers 2026-08-19 to 2026-11-08.

## Method (repeat each quarter)

1. Read `docs/competitors.md` in full: the profiles, the "Not yet profiled"
   table and the Feature inspiration updates. Use `git log -p` on the file for
   the quarter if a scan note has since been condensed.
2. Tag every dated finding with one or more themes: **features**,
   **acquisition / distribution**, **new segments**, **monetisation**,
   **funding / team / exits**, **provider-side moves**.
3. Count independent products per theme. A theme with three or more unrelated
   products converging on it is a pattern; one or two is a data point.
4. Score each pattern against the last edition: strengthening, stable, fading.
5. State the caveats (season, source quality, search bias) before the
   conclusions, not after.
6. End with what the pattern means for open Snowdesk tickets and the
   Feature inspiration list.

The edition is a synthesis of the scan notes, not new research. Anything it
claims inherits the verification level of the note it came from.
