## Process note: ticket-closure integrity

Seven tickets carried across recent cycles as "open/unresolved" (SNOW-166, SNOW-363, SNOW-364, SNOW-365, SNOW-366, SNOW-337, SNOW-321) were discovered this cycle to actually be marked **Done** in Linear, despite their underlying code findings being confirmed still present via direct grep/git-log checks against the current tree. The mechanism: this workspace's GitHub–Linear integration transitions any ticket referenced by identifier in a merged PR body to Done, and the code-review-pass skill's PR-body template (Step 10) lists every spun-off child ticket by identifier — so each cycle's own PR merge silently closes its own follow-up tickets, with no fix ever landing.

All seven have been reopened this cycle with an explanatory comment and re-parented under SNOW-450. A fix is tracked as [SNOW-451](https://linear.app/hugorodgerbrown/issue/SNOW-451). Until that lands, **this cycle's PR intentionally omits the "Child tickets" list from its body** — child-ticket links live in this doc instead — to avoid immediately repeating the bug it just diagnosed.
