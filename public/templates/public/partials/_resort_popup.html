"View bulletin" CTA linking to the region's evergreen bulletin page. Context variables expected: resort — regions.Resort instance. region — regions.MicroRegion instance (resort.region). favourited — bool: True when the requesting user already has a Favourite for this resort. favourite_uuid — str: the existing Favourite's uuid (for unfavourite), or "" when not favourited. can_favourite — bool: True when the ``favourites`` flag is active AND the requesting user is authenticated. signin_url — str: accounts:sign_in URL, for the anonymous/ineligible CTA. bulletin_url — str: URL to the region's evergreen bulletin page. {% endcomment %}
