{% comment %} public/templates/public/partials/_resort_meta_row.html — Resort-popup metadata row (SNOW-501). One label + value/placeholder row, reused for resort metadata fields whose value is a single plain-text scalar (operator, lifts, runs) in ``_resort_popup.html``. Blank fields are never omitted — they render a dashed-box placeholder so missing curation stays visible: an em-dash for public/non-staff visitors, an explicit "Add " hint for staff (``request.user.is_staff``), cueing them to curate. Rows whose value needs extra formatting or is composed from more than one model field (website link, piste length units, elevation range, season) are written inline in ``_resort_popup.html`` instead, reusing this partial's classes, since their guard/format logic doesn't fit a single truthy ``value`` slot. Context variables expected: label — str: field label (e.g. "Operator"). value — str: formatted value, or blank/None when unset. is_staff — bool: True renders staff_hint in the placeholder instead of the public em-dash. staff_hint — str: staff-facing curation hint (e.g. "Add operator name"). {% endcomment %}
