{% load i18n %} {% comment %} templates/includes/_sheet_header.html — Shared header for map fly-out sheets. Renders a title plus a persistent × close control. Used by any sheet state that lacks its own close affordance (favourites and reports map sheets). The × dispatches through ``data-action`` — it does not call JS directly. SNOW-486: ``close_action`` is conventionally ``"dismiss"`` — the owning sheet is a ``[data-overlay]`` element (includes/_overlay_sheet.html), so static/js/overlays.js's shared delegated handler picks up a ``[data-action="dismiss"]`` click without the sheet's own JS needing to bind a listener for it. Parameters (passed via ``{% include … with … %}``): title (string) — Heading text rendered next to the ×. close_action (string) — Value for the button's ``data-action`` attribute. Pass "dismiss" unless the owning sheet has its own bespoke close handler. title_class (string, optional) — Font-size/weight utilities for the title. Defaults to the original ``text-sm font-semibold``; the "Manage downloads" sheet (SNOW-645 review) passes ``text-lg font-bold`` for its own larger heading. ``text-text-1`` is always applied underneath whatever this carries, so callers only need to state size/weight. SNOW-645 review: the × used to be ``text-lg leading-none px-1`` — a ~26×20px hit target, well under the 44×44 minimum. The glyph itself is unchanged (still ``text-lg leading-none``); it is now centred inside an ``h-11 w-11`` (44×44px) box instead, so every consumer's close control gets a real tap target for free. Checked against both other consumers (``_favourites_surface.html``, ``observations/_report_form.html``) — both headers gain a little vertical room, which is the point, not a defect. {% endcomment %}
