{% load i18n %} {% comment %} templates/includes/_sheet_header.html — Shared header for map fly-out sheets. Renders a title plus a persistent × close control. Used by any sheet state that lacks its own close affordance (favourites and reports map sheets). The × dispatches through the sheet's existing delegated close-button listener via ``data-action`` — it does not call JS directly. Parameters (passed via ``{% include … with … %}``): title (string) — Heading text rendered next to the ×. close_action (string) — Value for the button's ``data-action`` attribute, matching the delegated listener the owning sheet already wires up (e.g. "close-favourite-sheet", "close-report-sheet"). {% endcomment %}
