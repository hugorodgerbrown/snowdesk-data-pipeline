{% comment %} templates/includes/_map_overlay_toggle.html — the "Show on the map" switch strip at the foot of a map panel. History. SNOW-645 built it inline as the downloads sheet's footer control; SNOW-658 extracted it here so the favourites and field-observation panels (and, with SNOW-687, routes) could carry the same footer. SNOW-904 deleted it, making the map's layers menu the sole control for every layer. The two-capsule control column brought it back, restored from that deletion, with one difference that matters: the layers menu stays the place that answers "what is on my map". This strip is a SECOND way in to ONE layer — the one the panel is about — bound to the same state as that layer's menu row (static/js/map_panel_overlay_switch.js), so flipping either moves the other. See docs/decisions/map-controls-are-two-groups-without-an-on-map-marker.md. The strip is a label plus includes/_switch.html, in its own light-grey rounded box (`bg-tag` — the same token the problem/chip tags use), so it reads as "and here is the map view this affects" after everything the panel itself holds.
