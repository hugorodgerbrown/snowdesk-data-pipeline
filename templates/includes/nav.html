{% comment %} templates/includes/nav.html — Persistent top navigation bar. Renders the Snowdesk wordmark plus an optional back link, an optional Season trigger button, and a right-side auth/admin area. Right-side auth area -------------------- Authenticated subscriber: An avatar button (first letter of email) opens a dropdown showing up to three subscribed region links, a "My account" link, and a "Sign out" button. Region links are provided by the nav_subscriptions context processor (accounts/context_processors.py). Not authenticated: A single "Sign in" button routes to /account/sign-in/; that page carries the "Create an account" link for new users. Staff overlay (separate from subscriber auth): A cog-icon button opens an admin dropdown: Component library, Push demo, Edit map, Django admin. Rendered in addition to the subscriber avatar — a staff user who is also a subscriber sees both. Sync badge (SNOW-376): A [data-sync-badge] pill sits alongside the avatar/register links, hidden by default. static/js/mutation_queue.js reveals it with the live non-"failed" queue:mutations depth ("N changes queued") and swaps its colour to the status-error tokens when any queued mutation has permanently failed. Network toggle (SNOW-748): A [data-network-toggle] icon button beside the sync badge, offered to every viewer including anonymous ones. Hidden by default; static/js/pwa_offline.js reveals it, paints its pressed state and binds the click, which asks the service worker for 'offline-forced' or 'auto'. Moved here from the offline banner, which only appears once the network has already failed — see the comment at the button itself. Parameters ---------- back_url : str, optional URL for a back-chevron link. Omit on pages where "back" has no obvious target (home, map). When present, a thin vertical divider separates the chevron from the wordmark. back_label : str, optional Label shown next to the chevron. Defaults to "Back" — prefer a destination-specific label ("Map", "Season") where possible so the user knows where the arrow leads. season_trigger : bool, optional When truthy, a labelled "SEASON" button is rendered right-aligned.
