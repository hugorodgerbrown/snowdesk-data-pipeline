{% load i18n %} {% comment %} templates/includes/_offline_toast_cta.html — the label slot of the connection-status toast's one CTA (SNOW-748). Rendered inside ``includes/_toast.html``'s CTA button via that partial's ``cta_label_template`` parameter, because the button has TWO labels and a plain ``cta_label`` string can only carry one. One button, two labels, one action. The action is identical — return to ``'auto'`` — but "Try reconnecting" reads as a repair, which is the wrong verb when nothing is broken and the user simply chose offline mode. Both are rendered here and toggled by ``hidden`` in static/js/pwa_offline.js; assigning either from a JS literal would ship English to every locale, because ``makemessages`` never scans ``static/js`` (docs/i18n.md). The button itself is offered only where it does something — ``pwa_offline.js`` hides it in ``'auto'``, where the app is already using the network, and while the app is merely struggling and still retrying on its own. It is the ONLY exit from an auto-latched state for an anonymous reader, who has no account menu and so no "Offline mode" switch. {% endcomment %} {% trans "Try reconnecting" %} {% trans "Use the network again" %}
