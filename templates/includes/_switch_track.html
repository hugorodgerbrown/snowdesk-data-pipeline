{% comment %} templates/includes/_switch_track.html — the drawn half of a switch, for a control that is already a button (SNOW-1266). includes/_switch.html is a real checkbox input, which is right for a form or a settings row. The map's layers menu is a role="menu" of menuitemcheckbox BUTTONS whose aria-checked is the state every script that reads the menu already uses (map.js seeds it, map_basemap_picker.js flips it, map_layer_sync_status.js disables it), so a second, hidden input there would be a second copy of the state to keep in step. This partial draws the same 44×26 track and 20px thumb as _switch.html and nothing else: it is aria-hidden, and it reads its state from the nearest ancestor carrying Tailwind's `group` class through `group-aria-checked:`. The caller's button is the control — its role, its label and its aria-checked. Measurements and colours are _switch.html's, for the reasons set out there (the thumb travels 44 − 20 − 3 − 3 = 18px). Parameters (passed via {% include … with … %}): demo_checked (bool, optional) — draw it on without a checked ancestor. The component library's variants only; a real caller leaves it unset so the button's aria-checked decides. {% endcomment %}
