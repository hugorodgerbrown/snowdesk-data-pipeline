{% load og_tags %} {% comment %} templates/includes/_page_meta.html — the one emitter for page-identifying head metadata (SNOW-553). Every page that extends public/base.html overrides {% block page_meta %} with a single {% include %} of this partial. Nothing else in the codebase emits , meta description, og:title, og:description, og:url, twitter:title or twitter:description — so a page cannot omit them by accident, only on purpose and in writing. Before this existed, only the home and bulletin pages set the three tags that identify a page. The other nine unfurled in Slack, WhatsApp, X and LinkedIn as a generic, un-deduped card — the resort page worst of all, since SNOW-504 built it specifically to be shared. Parameters ---------- title (required) Page title. Goes in <title> (with the staging suffix appended) and, when sharing is on, og:title / twitter:title (without it — the suffix is browser-tab disambiguation, not part of the page's name). description (required) One or two sentences. Goes in the description meta and, when sharing is on, og:description / twitter:description. Keep under ~155 characters so a search result shows it whole. sharing (optional, default True) Set False to emit the title and description but no og:*/twitter:* page identity. Only for pages that should never produce a share card — see below. noindex (optional, default False) Set True to emit <meta name="robots" content="noindex, nofollow">. It lives here rather than in the calling page because this partial is the ONE emitter for head metadata, and a second emitter is how a page ends up with two conflicting robots directives. `noindex` and `sharing` are INDEPENDENT, and the combination that looks contradictory is the one that matters: a tokenised trip page (SNOW-821) wants a full share card — unfurling in a message is the entire point of the link — AND wants never to be indexed, because the URL is unguessable and a search result for it would defeat that. robots.txt cannot express this: `Disallow: /trips/` would prefix-match the token path and block the very unfurlers the page exists to serve. og_type (optional, default "website") The og:type value. Pass "article" for dated, revisable content — a bulletin — which also unlocks the two properties below. og:type lives here rather than in base.html's og_tags block precisely so a page can vary it: a child template cannot un-emit a tag it inherits (SNOW-555). published_time / modified_time (optional) ISO-8601 timestamps, emitted as article:published_time / article:modified_time and only when og_type is "article". Pass the values the view derived via _build_article_times, never times recomputed in the template — the point is that the share card and the JSON-LD cannot disagree about when a bulletin was issued. url (optional) Absolute URL for og:url. Defaults to SITE_BASE_URL + the current request path. Pass an explicit value when the page has a canonical URL that differs from the URL being requested (bulletin.html passes canonical_url, so today's bulletin shares as its evergreen URL rather than its dated one). Both title and description are passed through |squish, so a multi-line block body reflowed by djangofmt cannot leak newlines and indentation into a content="…" attribute. Fixing it here means no future page can reintroduce that defect. Opting out ---------- sharing=False is the deliberate no-card path. Use it for pages that are private to one user, token-bearing, or staff-only — a share card for them is either meaningless or a small information leak. An opt-out MUST carry a comment saying why: silent omission is indistinguishable from an oversight, which is exactly how nine pages ended up with generic cards. og:url is emitted for opted-out pages too. It is the page's own identity, not a sharing affordance, and a page that declines a card still benefits from crawlers agreeing on which URL it is. Site-wide constants (og:site_name, og:type, og:locale, og:image and its dimensions, twitter:card) stay in base.html's {% block og_tags %} — they don't vary per page, so they don't belong in a per-page emitter. {% endcomment %} <title>{{ title|squish }}{{ PWA_TITLE_SUFFIX }} {# `is True` rather than a truthiness test, matching `sharing`'s own note #} {# below: an omitted `noindex` resolves to the empty string, and a page #} {# that acquired one by accident must stay indexable. #} {% if noindex is True %}{% endif %} {% if og_type == "article" %} {# Emitted only for og:type=article, so no other page carries orphaned #} {# article properties.
