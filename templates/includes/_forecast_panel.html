{% load i18n static weather_tags %} {% comment %} templates/includes/_forecast_panel.html — multi-day outlook for one location. One part: a compact day strip — one column per day, carrying the weekday label, condition icon, hi/lo temperature, that day's freezing level, its wind, and a snowfall chip when the day's ``snowfall_sum`` is non-zero. The column is ``w-24`` rather than ``w-20`` so the wind value keeps its unit — a bare number sitting under "2400 m" says nothing about which is which. Gusts are deliberately absent: ``_weather_panel.html`` has a wrapping row to spend on them and this column does not (SNOW-780). **The hourly half is gone (SNOW-786).** It was a second part here: one ``_collapsible_panel.html`` per day carrying a 24-row table, via ``_forecast_hourly_body.html``. Both that table and the SNOW-723 hourly chart answer "what happens through this day", and the table only existed because there was no chart. The chart replaced it rather than joining it, and it is rendered by the page beneath this strip rather than from inside it — see ``public/location_weather.html``. SNOW-761: the days come from ONE ``Weather`` row — its own ``observed_on`` leads, and the rest are the entries in its ``forecast`` column (``build_point_forecast_panel``). Before the rebuild they were N sibling rows from a second table. Consumer: the location forecast page (``/weather//``), and nothing else. SNOW-783 took this strip off the resort page and the favourite card — both drew the same week the forecast page already owned, the resort page once per curated altitude — so each of those now shows the day and links here. Context: panel : ForecastPanel — ``{"days": [ForecastPanelDay, ...]}`` from ``apps.weather.services.weather_display.build_point_forecast_panel``. testid_prefix : str — prefix for every ``data-testid`` in this partial and its included children. Defaults to ``forecast``. selector_name : str — optional. When set, each day carrying an hourly series becomes a radio control in a group of this name, and the strip acts as the day selector for the hourly charts beneath it (SNOW-787). Omit it and the strip is read-only, which is what the component library renders. The name is per-page, so two strips on one page can never share a group. {% endcomment %}
