{% comment %} templates/includes/theme_head.html — Dark mode FOUC prevention. Include this in BEFORE the stylesheet link. It synchronously applies the .dark class to based on the user's saved preference (localStorage) or OS setting (prefers-color-scheme), preventing a flash of the wrong theme on page load. There is no theme toggle. This reads a `theme` key that nothing in the codebase writes, so in practice it follows the OS setting — the key is kept because a browser that has one stored from an earlier build should still be honoured, and because it is the natural place for a toggle to write if one is ever added. SNOW-615 removed the `window.__setTheme` setter that shipped for that toggle and had no caller. The localStorage read is wrapped: Safari in private browsing, and any browser with site data blocked, throw on access rather than returning null. Unwrapped, that exception would abort this script before the class is applied — turning a storage restriction into a permanently light-themed page for a user whose OS is dark. {% endcomment %}
