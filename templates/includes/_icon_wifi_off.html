{% comment %} templates/includes/_icon_wifi_off.html — the "not using the network" glyph: ``_icon_wifi.html``'s arcs, struck through (SNOW-748). Deliberately the SAME arcs as its sibling plus one diagonal, rather than a second drawing of the same idea — a user reads the change as the same mark being negated, not as one icon replaced by another. Any difference in the arcs would be seen as meaning something. This is the mark the offline state wears throughout: the header connectivity symbol in ``includes/nav.html`` (which renders both marks and shows this one while the app is not reaching the server) and the "Offline mode" row in the same file's subscriber menu. A strike-through rather than a fade or a colour change: the surfaces that carry it also carry colour (the status-warning tokens), and colour alone cannot say "off" to a user who cannot distinguish it.
