{% comment %} templates/includes/_icon_wifi_off.html — the "not using the network" glyph: ``_icon_wifi.html``'s arcs, struck through (SNOW-748). Deliberately the SAME arcs as its sibling plus one diagonal, rather than a second drawing of the same idea. The two are the two states of ONE control — the header network toggle in ``includes/nav.html`` swaps between them in place — so a user has to read the change as the same mark being negated, not as one icon being replaced by another. Any difference in the arcs would be seen as meaning something. A strike-through rather than a fade or a colour change: the toggle's pressed state already carries colour (the status-warning tokens), and colour alone cannot say "off" to a user who cannot distinguish it.
