{% load i18n %} {% comment %} templates/includes/_overlay_banner.html — Persistent banner primitive (SNOW-486). Two positional variants sharing one set of conventions (icon + copy + optional CTA + optional dismiss): "strip" — full-width, in-flow edge bar (e.g. the off-season archive notice). Always visible when rendered; no dismiss. "floating" — fixed bottom-centre card (default). Used by JS-revealed nudges: the service-worker update banner, the Android/ Chromium install prompt. Not every existing banner-shaped surface is expressed through this partial — the offline banner (a
disclosure with bespoke data-role hooks — see includes/_offline_banner.html), the iOS install guide (a 3-icon diagram with no CTA — see includes/_pwa_install_prompt.html) and the mutation-queue failure banner (a custom slide transition owned by static/js/mutation_queue.js — see includes/_toast_banner.html) are structurally bespoke enough that forcing them through a single shape would change behaviour, not just markup, so they keep their own templates and only adopt the shared z-index tokens. Required context: variant — "strip" | "floating". body — description text (or the single line of copy, for "strip" with no title). Pass an already-translated string via ``{% trans "…" as var %}`` in the including template. Optional context: id — DOM id on the outer element. role — ARIA role. Default "note" (strip) / "status" (floating). aria_live — ARIA live-region politeness (floating only). Omitted by default — pass "polite" for a banner JS reveals asynchronously and wants announced (matches the original sw-update-banner contract); the install-nudge banners have never carried this attribute. kind — status-palette key ("warning" default) — strip variant only. icon — "calendar" (strip) | "refresh" | "location-off" (floating). Omit for none. position — "top" | "bottom" (floating only; default "bottom"). "top" anchors near the top-centre (clears the nav) — used by the off-map nudge; the update/install nudges use the default. title — heading text (floating only). When supplied, ``body`` renders as a second, smaller line; when omitted, ``body`` is the only line. title_id — id for the title

, referenced by aria-labelledby. body_id — id for the body

, mirroring ``title_id``. Only takes effect when ``title`` is also supplied — with no title the body IS the title (it already renders with ``title_id``); ``body_id`` gives a caller a hook to rewrite the body text at runtime (e.g. JS injecting a dynamic list of names into a floating confirm banner) without touching the static sentence that would otherwise sit in ``title``. cta_id — DOM id for an optional primary CTA button (floating only). cta_label — CTA button label, same translation convention as body. bottom_offset — Optional CSS ``bottom`` value overriding the default ``bottom-4`` (floating only) — e.g. so a banner clears the mobile season scrubber. Only legitimate use of an inline style here: an ``env(safe-area-inset-bottom)`` offset can't be expressed as a static utility. dismissible — Bool; default False. When True renders a "×" carrying ``data-action="dismiss"`` and marks the outer element ``data-overlay data-overlay-hide="class"`` so static/js/overlays.js's shared delegated handler can hide it (this partial always uses the Tailwind ``hidden`` CLASS idiom, matching every other shell-chrome overlay — never the HTML5 attribute). static — Bool; default False. When True the floating variant renders inline (no ``hidden``, no ``fixed``, no z-index) for the component library.
