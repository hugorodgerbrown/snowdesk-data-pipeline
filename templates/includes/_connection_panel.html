Four network states, carried over from SNOW-748, each named by its state line alone: * online (``online-message``) — the app is using the network. * struggling (``offline-message``) — requests are still being attempted. * latched (``latched-message``, "Try reconnecting") — the service worker has stopped calling the network after three read timeouts. * forced (``latched-message``) — the same, asked for by the user from the Offline mode switch; switching it off is the way back. The online state is what renders before any script runs, which is the right default: both offline modes are service-worker decisions.
