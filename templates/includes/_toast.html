Required when JS toggles visibility (SW banner, HTMX error banner). cta_label — Label for inline CTA button (paired with cta_href). cta_href — Sentinel value (e.g. "#") gating CTA emission. Used only by the component library so variants don't pile up at the viewport bottom. ARIA: kind in ("error", "warning") → role="alert" aria-live="assertive" otherwise → role="status" aria-live="polite" Display notes: ``flex`` is NOT baked into the base class. ``sw_register.js`` toggles ``hidden``/``flex`` on reveal (see static/js/sw_register.js lines 46–67), and the HTMX error JS only removes ``hidden``.
