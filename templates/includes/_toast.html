{% load i18n %} {% comment %} Fixed-position notification toast partial. Required context: kind — "info" | "success" | "warning" | "error" body — Body text (single line). Rendered via {{ }}, auto-escaped. Optional context: id — DOM id on the outer element. Required when JS toggles visibility (SW banner, HTMX error banner). cta_label — Label for inline CTA button (paired with cta_href). cta_href — Sentinel value (e.g. "#") gating CTA emission. Not used for navigation — the rendered button carries data-action="reload" so JS can wire its own handler. dismissible — Bool; default True. When true emits a "×" button with data-action="dismiss". static — Bool; default False. When True the toast renders inline (no ``hidden``, no positioning utilities; uses ``inline-flex``). Used only by the component library so variants don't pile up at the viewport bottom. visible — Bool; default False. When True the toast renders in its normal fixed position but already shown — ``flex`` in place of ``hidden``, which is the same pair ``sw_register.js`` toggles. For a toast whose reason the SERVER knows at render time (trips/trip_list.html confirming a trip it just wrote, SNOW-834), so the confirmation needs no JS to appear and survives a page with none. Pair it with ``timeout``: the shared controller in static/js/overlays.js arms on load for any ``[data-toast-timeout]`` that is not hidden. group — Str; optional name shared by toasts that occupy the same screen position and so must never be shown at once — a JS owner shows one and hides the rest of its group, matching on ``data-toast-group`` plus the ``data-kind`` every toast already carries (trips/trip_list.html renders a success and an error toast this way, so a failure is never painted in the success palette). timeout — Int; opt-in auto-dismiss delay in milliseconds. When supplied, renders ``data-toast-timeout`` and the shared toast controller (static/js/overlays.js) hides the toast that many ms after it becomes visible. Omit for a toast a caller dismisses itself (e.g. bulletin.html's share toast already runs its own timer — do not also pass ``timeout`` there, or the two would race harmlessly but redundantly). SNOW-486: the outer element carries ``data-overlay data-overlay-hide= "class"`` (except when ``static``) so a "×" click is caught by static/js/overlays.js's shared delegated handler for free — no per-page JS needed to wire the dismiss button, though a caller with its own reveal/hide logic (e.g. bulletin.html's share toast) may still bind additional listeners; the two do not conflict since both just toggle the same ``hidden`` class. ARIA: kind in ("error", "warning") → role="alert" aria-live="assertive" otherwise → role="status" aria-live="polite" Display notes: ``flex`` is NOT baked into the base class. ``sw_register.js`` toggles ``hidden``/``flex`` on reveal (see static/js/sw_register.js lines 46–67), and the HTMX error JS only removes ``hidden``. Adding ``flex`` here would break both patterns. {% endcomment %}
