{% load i18n %} {% comment %} templates/includes/_offline_banner.html — Persistent offline / freshness banner. Rendered hidden by base.html on every public page. Revealed by static/js/pwa_offline.js when: * ``navigator.onLine === false``, or * a fetch / HTMX request just failed with a network error. The banner is a ``
`` disclosure (SNOW-482). The summary row carries the offline message and a caret; opening it reveals two naturalistic sentences describing two distinct clocks so neither crowds the summary line: * "App last synced ." — when this device last reached the server (``sync.last_at``, persisted to IndexedDB ``meta:app``), rendered as a relative phrase ("6 minutes ago"); * "Data shown dates from ." — when the server generated the data it last returned (read from ``X-Data-Generated-At``, SNOW-370, persisted as ``freshness.last_generated_at``), rendered as a long date ("05 June 2026"). ``static/js/pwa_offline.js`` fills the two value spans (``data-role="synced-at"`` / ``data-role="data-at"``) from those clocks, falling back to an em dash when a clock is unknown. In-flow, not ``fixed`` — it sits as the first child of the body, above ``includes/nav.html``, so when revealed it pushes the nav and page content down rather than overlapping the nav bar. ``hidden`` collapses it to zero height. Spec §3.5, §10.1, §12.6 — freshness is non-negotiable. {% endcomment %}
