{% load i18n %} {% comment %} templates/includes/_offline_banner.html — Persistent offline / freshness banner. Rendered hidden by base.html on every public page. Revealed by static/js/pwa_offline.js when: * ``navigator.onLine === false``, or * a fetch / HTMX request just failed with a network error. Copy shows two distinct clocks (SNOW-482): when the device last synced with the server (``sync.last_at``, persisted to IndexedDB ``meta:app``) and when the server generated the data it last returned (read from ``X-Data-Generated-At``, SNOW-370, persisted as ``freshness.last_generated_at``). Once both are known the suffix reads "Synced HH:MM DD/MM · data from HH:MM DD/MM"; either clock degrades gracefully on its own when the other is unknown. In-flow, not ``fixed`` — it sits as the first child of the body, above ``includes/nav.html``, so when revealed it pushes the nav and page content down rather than overlapping the nav bar. ``hidden`` collapses it to zero height. Spec §3.5, §10.1, §12.6 — freshness is non-negotiable. {% endcomment %}
