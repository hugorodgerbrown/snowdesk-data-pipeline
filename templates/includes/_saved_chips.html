{% comment %} templates/includes/_saved_chips.html — the Saved panel's switch between Places, Routes and Observations (SNOW-1476). The installed phone app's Saved tab is the three existing sheets — the favourites, routes and report sheets, each its own surface — and this row, rendered under each one's header by includes/_ugc_panel.html, moves between them. static/js/app_tabbar.js listens for the change and closes one sheet as it opens its sibling, cross-fading the swap. The row is drawn only in the installed app on a phone (the standalone block in src/css/main.css); elsewhere each sheet is reached from its own roundel, as before. A segmented control (includes/_segmented_option.html), as the theme preference is: three radios, the current one checked. Parameters (passed via {% include … with … %}): current (string, required) — "places", "routes" or "observations": the sheet this row sits in. preview (bool, optional) — draw the row whatever the display mode. For the component library only. {% endcomment %} {% load i18n %}
