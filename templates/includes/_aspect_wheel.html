{% load i18n %} {% comment %} templates/includes/_aspect_wheel.html — the aspect wheel host (SNOW-1063). One route segment's heading and the way the ground under it faces, as two concentric compass rings, with the one-line summary under it. The markup is an empty host: static/js/aspect_wheel.js reads ``data-state`` and draws the SVG through ``self.pwaAspectWheelCore`` (static/js/aspect_wheel_core.js), then writes the line. The wheel is drawn client-side because its state moves with the route cursor; this partial exists so the registry at /_components/ can show every state, and so the strings template has a home ready for whichever route surface mounts the wheel. The strings template carries every word the wheel says — the compass points and the label and line patterns — under ``{% trans %}``, so makemessages sees them and no literal reaches the DOM from JavaScript. A page that renders several wheels renders the same template more than once; ``pwaStrings.read`` takes the first. Context: state_json : the wheel's state (``wheelState``'s shape), JSON-encoded. size : the wheel's size in CSS px, 16–200 (default 48). {% endcomment %}
