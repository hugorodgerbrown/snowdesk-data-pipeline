{% load i18n %} {% comment %} templates/includes/_terrain_filter_key.html — the terrain filter's colour key (SNOW-978). One key per mode, plus the row both share. The match mode paints matching ground in one tint; the slope mode (SNOW-1073) paints it by slope class on the 30/35/40/45/50+ ramp — the map's slope layer. Both hatch ground the tiles carry no data for. Rendered twice on the map page — in the map legend, and inside the filter's own sheet, because on a phone with a route open the legend is hidden and the sheet has to explain its own colours. One partial so the two cannot drift. Each mode's rows sit in a `display: contents` wrapper carrying data-terrain-filter-key="", so the wrapper adds no box and the rows keep the caller's layout. static/js/terrain_filter_sheet.js hides the wrapper for the mode that is not set; the server renders the match mode, the default. The swatches are .map-legend-swatch--terrain-* and --slope-* (static/css/map.css), painted from --color-terrain-* and --color-slope-* in src/css/main.css — the same values static/js/terrain_filter_core.js and static/js/slope_classes_core.js paint the map with. No parameters. {% endcomment %}
