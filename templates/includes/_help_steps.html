{% comment %} templates/includes/_help_steps.html — Numbered steps for a help article. The ordered list a step-by-step help article walks a reader through. Snowdesk had no
    anywhere in its template tree before this partial: /help/'s FAQ panels are prose, and `slf-prose` styles ul/li but never ol. The first article that needed numbered steps could either inline a class string or extract this, and the design system's rule is reuse first, extract second, inline never — so the styling lives here once rather than diverging across articles. Parameters (passed via ``{% include … with … %}``): body_template (string) — Django template path holding the ``
  1. `` items. The same slot-by-template shape includes/_collapsible_panel.html already uses, and for the same reason: the items carry translated strings, which have to stay whole msgids written at their call site rather than be assembled from a list passed through context. Numbering is ``list-decimal`` rather than a drawn badge, so the number a sighted reader sees and the position a screen reader announces are the same thing, and there is nothing to keep in sync. Nothing here needs custom CSS. {% endcomment %}
