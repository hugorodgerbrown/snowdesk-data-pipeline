{% comment %} templates/includes/_collapsible_panel.html — Reusable collapsible panel chrome. Renders a ``
`` wrapper with a summary row (title + chevron) and the outer body wrapper. Used by the four Snowpack & Weather panels on the bulletin page (Snowpack structure, Weather review, Weather forecast, Outlook/tendency). Parameters (passed via ``{% include … with … %}``): title (string) — Panel heading rendered in the ````. data_testid (string) — Value for the ``data-testid`` attribute on the ``
`` element. body_html (safe) — Pre-rendered safe HTML string. The partial wraps it in the canonical ``slf-prose`` div. Ignored when ``body_template`` is provided. body_template (string) — Optional Django template path. When present, the partial ``{% include %}``s it inside the body wrapper instead of outputting ``body_html``. Context inheritance carries ``prose`` and all other parent-context variables into the sub-template automatically. illustration (string) — Optional Django template path rendered ABOVE the body copy, inside the same body wrapper (SNOW-744). The help page uses it to show the real component a topic describes, fed by a synthetic context from apps.public.component_previews. It is decoration: the wrapper carries ``aria-hidden`` so a screen reader gets the prose alone, which therefore has to stand on its own without it. is_open (bool) — When truthy, renders the ``open`` attribute on ``

Used by the component library to demonstrate the opened visual state; real bulletin panels omit this parameter (default closed). bare (bool) — When truthy, drops the card chrome (background, border, radius, bottom margin) and titles the panel with an eyebrow instead of a summary heading. For a panel nested *inside* another card, where the full chrome would read as a card within a card and the caller has already drawn its own separating rule — the field-notes block on each problem card (SNOW-673). The chevron and marker-reset behaviour is shared with the chromed form, which is the point of the parameter: one collapsible implementation, two skins. {% endcomment %}
