{% load i18n %} {% comment %} templates/includes/_saved_tabs.html — the installed phone app's Saved tabs: Places, Routes, Trips, Observations (SNOW-1479; the Saved chips of SNOW-1476 before it). The Saved tab is four existing sheets — the favourites, routes, trips and report sheets, each its own surface — and this row, rendered in each one's header by includes/_ugc_panel.html (through includes/_sheet_header.html's ``lead_template``), moves between them. static/js/app_tabbar.js listens for the change and closes one sheet as it opens its sibling in the same box, so only the content changes. FOUR ICONS, THE SELECTED ONE NAMED. Each option is includes/_segmented_option.html with an ``icon_template``: the glyph of the thing the list holds (the design system's own icons), and the label shown only beside the checked one. The label is in every radio's accessible name all the same. With the + roundel beside them, the tabs are the whole header in the app: the sheet's title, context line, section label and × are `app-hidden` there. Drawn only in the installed app on a phone (`app-only`); elsewhere each sheet is reached from its own roundel and keeps its own header. A segmented control, as the theme preference is: four radios, the current one checked. Parameters (passed via {% include … with … %}): saved_tab (string, required) — "places", "routes", "trips" or "observations": the sheet this row sits in. preview (bool, optional) — draw the row whatever the display mode. For the component library only; it also draws the Trips option. favourites_eligible (bool, from the map's context) — the reader is signed in. Trips is offered only then: its sheet, public/partials/_trips_surface.html, renders on the same condition, and a Trips option with no sheet would check and do nothing. {% endcomment %}
