{% load i18n %} {% comment %} templates/includes/_pwa_update_modal.html — Non-dismissable PWA update modal. Rendered hidden by base.html on every public page. Revealed by static/js/pwa_version_check.js when ``/api/version`` answers ``update_required: true`` — the server has listed this build in ``settings.APP_BLOCKED_VERSIONS`` (spec §3.4 forced-update, SNOW-609). The modal stays open until the user clicks "Reload now"; nothing is cleared and nothing reloads before that click. So the body copy states the consequence up front — clicking clears the offline copy of the app itself. Downloaded maps and saved data are named explicitly as surviving, because "clears" on a mostly-offline app otherwise reads as "deletes my 500 MB of downloaded maps". SNOW-486: markup delegated to the shared modal primitive (includes/_overlay_modal.html) — this file now only supplies the copy/ids. See that partial's header comment for the design contract (full-screen backdrop, centred card, no dismiss).
