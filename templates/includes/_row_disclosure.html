{% load components %} {% comment %} templates/includes/_row_disclosure.html — a UGC row's trailing expand control (SNOW-711). includes/_ugc_panel_row.html's `disclosure_template` slot: the chevron at the row's trailing edge that expands the row's own detail underneath it, into the element `disclosure_panel_id` names. Its one caller today is the account page's favourite row (favourites/partials/_favourite.html). A CHEVRON, NOT AN ARROW, because this expands in place rather than navigating: the same meaning includes/_collapsible_panel.html and static/js/map_controls_collapse.js already give the mark. What it replaces on that row is a "Details →" text link, which said the opposite and led to a separate page — two controls doing one thing, one of them the odd typographic control on a row of icon controls. STILL A REAL LINK. `href` is the row's own detail page, so the control works with no JavaScript at all and a middle-click still opens the page in a new tab. The `hx-get` is what makes it a disclosure when JS is running: HTMX swaps the detail fragment into the panel and the click never leaves the page. The hx-get is load-bearing beyond convenience for favourites — static/js/favourites_offline.js writes the fetched card through to IndexedDB on `htmx:afterOnLoad`, an event a full-page navigation never fires. COLLAPSE IS JS. `aria-expanded` starts false and is flipped by the surface's own module, which also empties the panel on the closing click. (The one caller was /account/favourites/ via static/js/account_favourites.js until SNOW-803 removed both; the map rows pass ``hide_disclosure``.) With no JS the control degrades to its href, which is why the closed state is the one rendered. Parameters (passed via {% include … with … %}): disclosure_href (string, optional) — the plain-navigation destination. Omitted, the control has no href and is hx-get only (SNOW-800: a favourite row whose pin has no location yet has no page to reach), and is made focusable as a button so the keyboard can still expand it. disclosure_hx_get (string, optional) — fragment URL for the in-place expand. Omit it and the control is a plain link. disclosure_panel_id (string) — DOM id of the element the fragment is swapped into; also the control's `aria-controls`. disclosure_label (string) — the control's aria-label. Name the ROW, not the action: "Details" alone names nothing with a list of rows on screen. disclosure_testid (string, optional) — `data-testid` on the control. disclosure_expanded (bool, optional) — render the OPEN state. For the component library, which loads no interaction JS and would otherwise only ever show one of the two states.
