{% load i18n %} {% comment %} templates/includes/_forecast_chart.html — outlook temperature chart (SNOW-761). The daily max/min band across the forecast window, as one inline SVG. Sits directly above includes/_forecast_panel.html in the map's weather sheet: the chart carries the SHAPE of the week (warming, cooling, a thaw crossing zero) and the strip under it carries the figures. Neither repeats the other. Server-rendered, with no JavaScript and no charting library. The geometry is computed by apps.weather.services.weather_chart.build_forecast_chart and arrives here as plain coordinates; this file owns only how it looks. COLOURS COME FROM `currentColor`, NOT FROM `fill`/`stroke` LITERALS. CLAUDE.md allows a hex in an SVG attribute, and that allowance is what would have made this chart theme-blind: a literal here cannot follow the dark-mode override in src/css/main.css. Each group instead carries a design-token text class and the shapes inherit it, so the chart re-colours with the rest of the page. The 0 °C line is drawn only when the window actually crosses it — see `zero_y` in the service. Above or below freezing all week, it would be a line pinned to the edge of the plot claiming to mean something.
