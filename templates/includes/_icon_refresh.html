{% comment %} templates/includes/_icon_refresh.html — the "pick up the new version" glyph: two arrowheads on a two-arc cycle (SNOW-869). Its caller is includes/_overlay_banner.html's "refresh" icon variant, which is the service-worker update banner's roundel — static/js/sw_register.js spins this mark while the update it is offering applies. Why it is a partial. This was the one glyph in the tree that lived inline in a calling template rather than behind an _icon_*.html, and it was corrupt: it kept the top arrowhead and one arc, dropped the second subpath, and left the arc's `L23 10` running as a straight chord back across the circle. Nobody had a second copy to compare it against. One source per mark is how the other seventeen avoid that — see includes/_icon_chevron.html. The shape is Feather's `refresh-cw`: an arrowhead at each end of a two-subpath arc, so the cycle reads as continuous rather than as a circle with a line through it. Stroke width 2, matching every other glyph in this codebase — see includes/_icon_pencil.html's own note, and docs/decisions/ui-icons-are-house-stroke-partials.md for the rule this corrupted path is the reason for.
