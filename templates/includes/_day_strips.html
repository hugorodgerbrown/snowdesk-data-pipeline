{% load i18n %} {% comment %} templates/includes/_day_strips.html — one day's weather as four linked strips with a row of figures under each (SNOW-1219). Built by apps/weather/services/day_strips.py (``build_day_strips``). The map's weather sheet shows it in place of ``_hourly_chart.html`` for each day that carries an hourly series; the location page keeps the meteogram. ONE TIME SELECTOR, ONE LINE: the hour scale 00–24 in a pill track, the selected three-hour block a dark capsule naming both its ends. Eight buttons cover the eight blocks. Pressing one, or dragging along the track, moves the selection. The plots themselves are not a control: a touch on a chart is a scroll, and a chart can be in view while the timeline that names the time is not. static/js/day_strips.js does that; without it the server's choice (the current block today, 09–12 on another day) is drawn and stays. THE SELECTION IS TWO THINGS, kept apart on purpose: ``--block`` on the section places the capsule and the band in every strip. One custom property, so they cannot drift apart. ``data-selected`` on each marks the boundary labels inside the block-indexed element capsule, the bold figure in each row and the one visible summary in each header. ONE BAND PER STRIP: each strip's plot and its figure row are one grid, and the band is a grid item spanning both rows of the plot column, so the highlight is a single shape from the top of the plot to the foot of the figures, with no seam and nothing to fall out of step when it moves. The selected figure takes only weight and colour; the band is its background. The CSS for both is "Day strips" in src/css/main.css. GEOMETRY: every strip and every figure row is a two-column grid whose first column is the same gutter, so the plot and the eight figure cells share one x. The plots stretch horizontally only (``preserveAspectRatio="none"``, non-scaling strokes); labels and arrows are HTML, as in the meteogram.
