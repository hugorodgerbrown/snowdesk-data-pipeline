{% comment %} templates/includes/_day_pyramid.html — Elevation danger pyramid (SNOW-298). Renders a two-tone mountain-silhouette SVG for ALBINA / Météo-France bulletins where a single validTimePeriod carries two distinct danger levels split by elevation band (e.g. considerable below 2400 m / moderate above 2400 m). The SVG uses two triangles drawn in sequence: 1. A full-height base triangle (lower-band colour fills the whole shape). 2. An apex triangle overlaid on the top portion (upper-band colour). A horizontal dividing line marks the split boundary. Fills come from CSS classes (.dp-seg.lv-*) backed by --color-eaws-* tokens — no raw hex values in this template. Numerals use .dp-num.lv-* which maps to --color-eaws-*-fg. Required context (passed via {% include … with group=g %}): group.type — validTimePeriod string (e.g. "all_day") group.pill_label — text for the time chip (e.g. "All day") group.lower — row dict for the low-elevation band: level_css, level_number, level_label, caption group.upper — row dict for the high-elevation band: level_css, level_number, level_label, caption {% endcomment %}
