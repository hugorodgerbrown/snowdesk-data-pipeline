One row per validTimePeriod (earlier / all_day / later); pure type + colour, no problem icons (those are the rating blocks' job). Elevation-banded periods (ALBINA / Météo-France) emit two rows for the same period — one per band — each carrying an ``elevation_bounds`` object. Single-band periods (all SLF, constant-danger ALBINA) leave ``elevation_bounds`` unset and render the plain chip row (SNOW-298).
