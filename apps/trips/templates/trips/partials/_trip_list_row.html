{% load i18n components %} {% comment %} trips/partials/_trip_list_row.html — one row of the trips agenda (SNOW-823). A row, not a card: a list should read as a list. The day and time lead, because an agenda is read by when — the label answers "which one" only after the reader has found the right morning. ORGANISING IS A LABEL, NOT A SECTION. A trip the reader authored gets a chip saying so and sits in date order with everything else. Splitting the list by authorship would file two trips on the same morning under different headings, and the reader's question is "what am I doing", not "what did I write". The row is a link to the trip, and — for a trip the reader ORGANISED — a Share button beside it (SNOW-834). The button is a sibling of the anchor rather than inside it, because a button nested in a link is neither valid nor operable. Minting is organiser-scoped in mint_trip_share, so a row for somebody else's trip carries no button at all rather than a disabled one: the site's "show controls, don't hide them" rule is about a control the reader could earn the right to press, and this is not one. SHARING AGAIN ROTATES THE LINK, which stops one already sent to a group chat working. The label says which press this is — "Share" for a trip with no live link, "Share again" for one that has — and the consequence rides in the button's title, the same sentence _trip_share_controls.html prints under the buttons on the trip's own page. It is not a UGC panel row (includes/_ugc_panel_row.html): that shape carries a rename pencil and a trash can for an object edited in place, and a trip is edited on its own page by one of the several people on it. Context: trip : Trip — the trip to render. created_trip : Trip or None, optional — from the outer context. When it is this trip, the row is marked as the one just written, so the confirmation toast has something to point at on an agenda with several trips on it. Compared as objects: two model instances with the same primary key are equal, and a None never matches, so no guard is needed around the test. {% endcomment %}
