{% load i18n static %} {% comment %} trips/partials/_trip_map.html — the trip's map canvas and its payload. One MapLibre canvas showing the route as a line with a marker where the group meets, plus the elevation profile underneath it. Drawn by static/js/trip_map.js from an INLINE payload rather than a fetched one: the page already holds every byte of it, it is small, and a public share page that had to make a second request to draw its own map would show a recipient nothing at all while that request was in flight. THREE MODULES LOAD BEFORE trip_map.js AND THE ORDER IS LOAD-BEARING. Deferred scripts run in document order, so `self.pwaElevationProfileCore`, `self.pwaRouteMarkersCore` and `self.pwaStrings` all exist by the time trip_map.js's top level runs. The first two are reused UNCHANGED from the map page — they already publish frozen globals, own no map state, and the elevation profile a trip draws is the same picture a route popup draws of the same geometry. has an explicit height rather than an aspect ratio: MapLibre measures its container on construction, and a container whose height is still resolving gives a canvas of zero pixels that never repaints.
