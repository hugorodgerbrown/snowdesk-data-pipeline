{% load i18n components %} {% comment %} trips/partials/_trip_roster.html — who is going, and the viewer's own verb (SNOW-822). Rendered on both trip surfaces, and re-rendered by trips:join / trips:leave as the swap target, so the count, the names and the control can never disagree about what just happened. THE DISCLOSURE RULE, which this file enforces and apps/trips/services/participants.py states: * ANYONE HOLDING THE LINK SEES THE COUNT. "Four people are going" is what a recipient needs to decide whether to come, and it identifies nobody. * ONLY PARTICIPANTS SEE THE NAMES. A trip link travels — forwarded out of a group chat, pasted into another one — and the people on the roster did not agree to be listed to whoever it reached. Joining is what earns the group's names. * THE ORGANISER IS NAMED TO EVERYONE. They authored the thing and sent it; their name is already the answer to "who is this from", and withholding it would make the page more anonymous than the message that carried it. THE VIEWER'S CONTROL IS ONE OF FOUR STATES, and none of them is nothing: the organiser → no control at all, plus a line saying so. They cannot leave (a trip whose organiser is not on it is incoherent) and the exit is Delete, which the page's own delete disclosure already offers and describes. a participant → Leave. signed in, not on it → Join. signed out → a sign-in link. Never a Join button that posts to a 403. There is no Remove control anywhere, for anybody. Removal is a moderation surface with its own questions and a trip lasts one day; deleting the trip is the one lever, and it is honest about taking everyone with it. Context: trip : Trip — the trip whose roster this is. roster : list[TripParticipant] — every account on it, in join order. roster_names_visible : bool — the disclosure rule's answer for this viewer. is_organiser : bool — whether the viewer authored the trip. is_participant : bool — whether the viewer is on it. join_url : str, optional — set on the share page only; the token-addressed join endpoint. leave_url : str, optional — set when the viewer may leave. {% endcomment %}
