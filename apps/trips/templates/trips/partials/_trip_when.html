{% load i18n weather_icons %} {% comment %} trips/partials/_trip_when.html — the Plan form's "When": the day as five tiles and an "Other", then the meeting time (SNOW-1215). THE WEATHER DAY PICKER'S PATTERN (includes/_weather_day_picker.html), so the two week strips in the product read alike: a white tile per day, and the checked one marked by an accent border AND a marker bar under it — two channels, neither of which moves the tile. Never a black fill, which is what the native date field this replaces looked like on an iPad once a day was picked. Each input/label pair has its own wrapper for the reason that partial gives: ``peer-checked:`` is the general sibling combinator, and the wrapper bounds it to one pair. THE RADIOS ARE THE FIELD. Every tile is a ``name="date"`` radio whose value is its day, so the form posts a day with no script at all. "Other" is a radio too; its value is whatever day static/js/trip_form.js last read off the native date input laid over the tile, which opens the system's own date picker. A day already outside the week — a trip planned further out, or an edited trip already past — arrives checked on "Other", which shows it. THE DANGER LEVEL, WHEN THERE IS ONE. A tile shows the route region's level for its day as a compact ``.danger-tile`` when a bulletin rated that day (apps/trips/services/plan_days.py), and an empty slot of the same height otherwise, so the tiles never change height. Most days have none — a bulletin covers today, and tomorrow once the evening issue is out — and that is the intended reading, not a gap. The line under the tiles names the checked day, and its region and level when there are any. One per tile is rendered; the script shows the checked tile's, and the server shows it first, so it reads without the script. THE FORECAST, WHEN THERE IS ONE (SNOW-1217). Each tile shows the day's weather icon and high from the forecast point nearest the route's start (apps/trips/services/trip_weather.py), with the danger chip under it on the days a bulletin rated. The line under the captions names the point, its height and how far it is from the start (includes/_forecast_source.html), because it is not the start: a route has no forecast of its own, and the point is borrowed at any distance (2026-10-28). With no curated point holding today's row the tiles carry no weather slot at all, rather than seven empty ones.
