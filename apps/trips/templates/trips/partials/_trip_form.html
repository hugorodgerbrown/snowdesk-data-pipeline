{% load i18n components %} {% comment %} trips/partials/_trip_form.html — the organiser's plan, as a form. ONE form for both halves of authoring. Creating posts to trips:create with the source route's uuid riding in a hidden field; editing posts to trips:edit, whose URL already names the trip. Which of the two is decided by ``trip_uuid`` being set, and nothing else differs — the editable fields are identical, because the snapshot is not editable and has no field here at all (see apps/trips/models.py). A FRAGMENT POSTED OVER HTMX, from a full page. The form itself lives on a page (trips/trip_new.html, or the organiser's own trip page); the POST is a fragment endpoint so an invalid submission can come back as this same file with its errors and swap itself in place, without a round trip through a full re-render that would lose everything else the page holds. A successful post answers HX-Redirect and the browser navigates. `hx-swap="outerHTML"` on the form's own id: the response IS this form, so the swap replaces it rather than nesting a second copy inside the first. THE MEETING POINT IS A PIN ON A MAP, in _trip_meeting_picker.html. It began as two number inputs prefilled with the route's start, which only works for someone who knows what 46.080012, 7.318197 is — nobody does. The inputs are still there and still the value this form posts, but SNOW-840 made them hidden: the sentence that stood here said they were "now under the map rather than in front of it", and now they are behind it. See _trip_meeting_manual.html for the three cases that lost their control. THREE NUMBERED SECTIONS AND A FOOTER (SNOW-1215): 1 When (the day tiles and the time, _trip_when.html), 2 Where you meet (the picker), 3 Details (optional — the trip name, whose placeholder is the route's name, and the note, whose placeholder is an example). The footer stays in view and reads the plan back as it is chosen, beside Cancel and Create. The Plan page frames each section as a card; the trip page's "Edit this trip" is already inside one, so there the sections are divided by a rule instead. Context: form : TripForm — bound or unbound. framed : bool, optional — each section its own card (the Plan page). Off inside the trip page's edit disclosure. plan_week, plan_date, plan_other, plan_other_date : _trip_when.html's; see apps/trips/views.py ``_plan_context``. route_uuid : str, optional — the source route. Set on the CREATE path. trip_uuid : str, optional — the trip being edited. Set on the EDIT path. Exactly one of the two is ever set. cancel_url : str, optional — where Cancel goes. Omitted on the edit path, where the form is already on the trip's page. picker_payload : dict — the meeting picker's route line, bounds and initial pin. Passed straight through. basemap_url : str — likewise. what3words_active : bool — likewise; SNOW-840.
