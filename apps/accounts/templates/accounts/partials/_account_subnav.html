{% comment %} apps/accounts/templates/accounts/partials/_account_subnav.html — Account-area sub-nav (SNOW-667). Persistent navigation across the account child routes, grouped by what the user is doing: "Your data" (things they have saved) and "Settings" (things they can change about the account). Groups and entries are rendered from ``subnav_groups`` — a list, not a hard-coded pair — so a new child route is a data change in ``apps.accounts.subnav.build_subnav`` rather than an edit to this markup. SNOW-668 (places), SNOW-677 (observations) and any future /account/routes/ slot in that way. Parameters (passed via ``{% include … with … %}``): subnav_groups (list) — Groups to render.
