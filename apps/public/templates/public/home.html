{% extends "public/base.html" %} {% comment %} apps/public/templates/public/home.html — the marketing homepage at /. A static page: a screenshot of the map, a one-line pitch, a link into the app at /map/, and short sections on what a reader gets from Snowdesk. The pitch is local conditions and route analysis — one place, one day — so the sections follow the order a tour is prepared in: the bulletin, the weather, the line, the line against the day, the trip, the hill without signal. Snowdesk analyses a route the reader brings as a GPX; it has no route planner, so the copy never says "plan a route". Cross-border coverage is a footnote, not the lead: a reader is in one place. It loads no map JavaScript and no MapLibre CSS — the image is a JPEG (static/img/home/map.jpg), not a live map, so the page stays light enough to be the first thing a new visitor downloads. The copy argues from what a reader gets, never from how it is built. It is a DRAFT for review; the sections are independent, so one can be cut or reordered without touching the others. The map itself is public/map.html.
