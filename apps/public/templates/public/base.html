{% comment %} apps/public/templates/public/base.html — Canonical layout for the public site. Pulled out of bulletin.html (the "most complete, use as base" page flagged in SNOW-9). Every public page extends this template, including home.html (which hosts the map at /). Subscription pages (apps/accounts/templates/accounts/) also extend this file directly. Blocks ------ page_meta : page identity — , meta description, og:url, and the og:/twitter: title+description pair. Every page overrides this with a single {% include "includes/_page_meta.html" with title=… description=… %}. Pass sharing=False (with a comment saying why) for a page that should never produce a share card. There is no separate title / meta_description block: one emitter is the whole point, so that a page cannot half-set its metadata or omit it by accident (SNOW-553). og_tags : OpenGraph / Twitter card constants that do not vary by page — og:site_name, og:locale, og:image and its dimensions and alt text, twitter:card, twitter:image, twitter:image:alt. Pages should not need to override this; per-page identity belongs in page_meta. favicon : the <link rel="icon"> tag. Default points at the plain favicon.svg; bulletin.html overrides with a level-tinted variant matching the page's danger rating. extra_head : page-specific <head> content (stylesheets, scripts, embedded JSON). Loaded AFTER output.css so page-level overrides win. body_class : Tailwind classes on <body>. Default gives background, text colour, font, min-h-screen, and flex-col so pages with a centred hero (home.html) can rely on flex-1 to fill remaining vertical space. nav : top navigation. Default = the plain wordmark variant; pages that want a back-chevron override this block. content : the page body. site_footer : the global site footer. Default = the small SLF attribution + Terms link partial introduced in SNOW-30 to satisfy the SLF CC BY 4.0 licence. Pages with a richer per-page footer (bulletin.html) still inherit this line below the rich one — the rich footer is page-content; this is the site licence line. Override with {% block site_footer %}{% endblock %} only if a page needs to reposition the licence line (e.g. into a floating overlay), not to remove it. extra_js : scripts loaded at end of <body>.
