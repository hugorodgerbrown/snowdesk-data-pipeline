{% comment %} apps/public/templates/public/_site_footer.html — Global site footer. Renders on every page that extends public/base.html: the site's legal links and the release the server is running. SNOW-769 removed the provider-attribution block that used to sit here. It named SLF, ALBINA and Météo-France on every page, and it was the third copy of the same three links: the map legend carries its own "Avalanche data" section, and the colophon carries the full licence text for all three, which this footer still links to. On a bulletin page the attribution that matters is the per-bulletin "Source" link in the metadata strip, which names the service that issued the bulletin the reader is actually looking at. The SLF CC BY 4.0 obligation from SNOW-30 is satisfied by the colophon, as it always was. The release label comes from ``apps.public.release.release_label`` via the ``pwa_version`` context processor. It lived in the account menu until SNOW-769, which meant it was invisible to anyone not signed in — the people most likely to be asked which version they are on. It is a value rather than copy, so it sits outside the blocktrans, and it is guarded: an unnumbered build renders no label and no trailing separator. The legal link points straight at /terms-of-service/, not at /terms/, which SNOW-770 turned into a redirect to it. Its label matches that page's own heading, which is the rule SNOW-769 set for this line. SNOW-836 added "Compare apps" (/compare/). It sits beside Help rather than among the legal links because it is orientation, not obligation: it is the page that answers "is this the right app for me at all", which is a question a first-time visitor asks and has nowhere else to ask. Kept deliberately minimal: one line. Visual weight should not compete with page content. Five links is the ceiling — a sixth wraps on a phone, and a wrapped footer reads as two rows of equally-weighted links rather than as one quiet line. {% endcomment %} {% load i18n %}
