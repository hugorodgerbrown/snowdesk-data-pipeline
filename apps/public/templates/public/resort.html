THE PAGE ANSWERS THE QUERY (SNOW-1124, docs/decisions/a-resort-page- answers-the-query.md, amending SNOW-807's docs/decisions/two-documents-and- a-map.md for resort pages). People search "Verbier avalanche", not "CH-4115", and a page that only links onward cannot rank for that — so today's danger is shown here. It is the bulletin page's own render model, selected the same way and rendered through the same partials, read-only: the bulletin stays the one full document, and this page holds no copy. FRAME (SNOW-1155, to Hugo's approved design board). A header, then two columns on a desktop (``lg``): the sections below in a main column, and the curated facts in a ~320px sidebar (``lg:w-80``).
