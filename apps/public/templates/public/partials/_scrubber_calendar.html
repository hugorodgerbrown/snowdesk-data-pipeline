{% load i18n %} {% comment %} public/partials/_scrubber_calendar.html — the scrubber's date picker (SNOW-792): a month grid that opens above the season scrubber and commits a chosen day through the scrubber's own commit point. The scrubber track is a few hundred pixels wide and spans a seven-month season, so a pixel is about a day and hitting a chosen date by drag is a fiddle. This is the precise route to the same place — it does not replace the scrubber, and it owns no commit path of its own: picking a day dispatches ``snowdesk:scrub-to`` and map_scrubber.js does the rest. Included by _map_embed.html INSIDE #season-scrubber, which is ``position: absolute`` and so is the containing block this popup anchors to. It is also included by the component-library demo, which renders the same markup inert. Context expected: * season_start — datetime.date: first selectable day. * season_end — datetime.date: last selectable day. * today — datetime.date: for the today marker. * calendar_month_names — 12 localised month names, January first. * calendar_weekday_abbrs — 7 localised weekday abbreviations, Monday first. The grid itself is built by static/js/map_scrubber_calendar.js rather than server-rendered: seven months of a season is ~245 day buttons, and putting all of them in the home page's DOM for a control most visits never open is a cost every visitor pays for a few who don't. What the server DOES supply is every translated word — the month names below travel as a data attribute and the weekday header is rendered here — so no user-facing string is a JavaScript literal (see docs/i18n.md). {% endcomment %}
