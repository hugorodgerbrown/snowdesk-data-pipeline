Formatting: elevation carries a thousands separator ("1,500–3,330 m", ``intcomma``); the season reads "1 Dec – 30 Apr"; the website value is "Official website" with the house external-link glyph, underlined, opening in a new tab. Two deliberate differences from ``_resort_meta_row.html``, which renders the same underlying fields in the map's resort popup: * That partial never omits a blank field — it renders a dashed-box placeholder so missing curation stays visible to staff. This block does the opposite: an unset field renders no row at all, and the whole section (eyebrow included) is omitted when every field is unset. The popup is a curation surface; this is a public detail page, and it follows the same no-empty-state discipline as the sections around it. * The label primitive here is the shared ``includes/_meta_cell.html``, reused rather than re-inlined per design-system rule 1. Numeric fields test ``is not None`` rather than truthiness, so a genuine zero (no lifts, no piste) renders as the fact it is instead of vanishing. Elevation and season each compose two nullable columns into one row and degrade to a one-sided "from"/"to" reading when only one end is curated.
