{% load i18n %} {% comment %} public/partials/_map_layers_zoom_label.html — the name line of a zoom-limited layers-menu row (SNOW-1280, reworked 3 Nov 2026). Included inside a row's .basemap-menu-item-text, in place of its bare [data-row-label], by the rows whose layer draws only past a zoom: Steep terrain and SAC ski touring (public/partials/_map_embed.html) and Wildlife rest zones (public/partials/_map_layers_switch_row.html, ``zoom_gate``). Nothing names the zoom level: the zoom control's scale does that. While the map is outside the layer's range — on or off — the row dims (``data-zoom-hidden``, set by map_layers_zoom_gates.js) and the HINT shows on the name's own line: "· zoom in" (or "· zoom out" for an up-to gate). The line never wraps, so the row's height is the same at every zoom (Hugo, 3 Nov 2026: "it doesn't shift in height as you zoom in/out"). The row's [data-row-label] stays the bare name: map_basemap_picker.js reads it to build the section summaries.
