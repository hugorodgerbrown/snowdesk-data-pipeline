The partial owns its own blank state (staff hint / register prompt / nothing). 3. Metadata rows (SNOW-501): operator, website, lifts, runs, piste length, elevation range, typical season. Either the favourite/unfavourite star (``can_favourite``) or a sign-in CTA. 5. "View resort →" CTA linking to the resort's own page (SNOW-504) — the bulletin link itself now lives on that page rather than in the popup.
