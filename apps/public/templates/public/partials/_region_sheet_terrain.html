{% load i18n %} {% comment %} public/partials/_region_sheet_terrain.html — the region sheet's "Show problem terrain on the map" switch, its colour key, and the rules it paints (SNOW-979). Above the bulletin, under the region's name and date (Hugo, 22 Oct: mockup option A). The strip is the panels' own "Show on the map" switch, ``includes/_map_overlay_toggle.html``, inside a box of the same ``bg-tag`` that also holds the key, so the two read as one control. The key lists only what the day can paint: one swatch per level a problem is rated at, the undecided grey when a problem cannot be placed, then the hatch for steep ground no problem describes and the no-data hatch, which every day can show. The line under it says what the shading claims and what it does not — where the bulletin describes its problems, not a hazard map. ``static/js/map_region_sheet.js`` binds the switch to ``window.pwaBulletinTerrain`` (map.js), shows the key while it is on, and shows the zoom line while the map is too far out for the tiles. The key and the zoom line render ``hidden`` so a body painted from the cache does not flash them before the script has read the switch's state. The swatches are ``.map-legend-swatch--*`` (static/css/map.css), painted from the same tokens static/js/bulletin_terrain_core.js paints the map with. Context (from apps.public.region_sheet.region_sheet_partial): terrain_rules — the rules, written out as a json_script for the page. terrain_key — ``levels`` [{level, label}] and ``undecided``. {% endcomment %}
