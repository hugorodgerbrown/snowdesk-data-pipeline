{% load i18n %} {% comment %} public/partials/_season_scrubber_controls.html — the transport controls and the draggable track that together make up the scrubber media-player UI. Included by /map/ inside #season-scrubber and by the component library at /_components/?slug=season-scrubber. Controls (left to right): skip-to-start, play-reverse, [track], play-forward, skip-to-end, calendar. The calendar is the odd one out and is placed last for that reason: the four transport controls move you ALONG the season, it jumps you to a named day (SNOW-792). Its tap target belongs here, with the other date affordances — the surface it opens does not, and sits in the bottom-right overlay slot with the favourites, observations and routes panels (public/partials/_map_calendar.html). Context expected: * today — a date (used to label the floating date pill). * today_pct — float 0..100, the thumb's starting position. {% endcomment %} {% comment %} Skip-to-start transport button — jumps the scrubber to the first date in the season. Falls back to data-season-start before the ratings cache resolves. {% endcomment %} {% comment %} Reverse / stop transport button — plays the timelapse backwards from the current thumb position. Second press stops. Mirrors the play button's dual-icon pattern: a left-pointing triangle for the reverse state and a stop square for the playing state. {% endcomment %} {% comment %} Play / stop transport button — starts timelapse from the current thumb position at 1× speed. Second press stops. {% endcomment %} {% comment %} The track holds both the draggable thumb and the floating date pill so the pill percentage is track-relative (not scrubber-relative, which would include the button widths). No aria-hidden: the pill inside carries aria-live so it must remain in the accessibility tree. {% endcomment %}

Empty until a region is selected — the track shows its grey rail. {% endcomment %}

Falls back to data-season-end before cache. {% endcomment %} {% comment %} Calendar button (SNOW-792) — opens the month grid that jumps the map to a chosen day. Last in the row, after the transport pair, because it is not a transport step: the other four move you along the season, this one jumps you to a named day. Carries .scrubber-transport-button so the existing data-state="loading" and "error" rules hide it with the rest — it must not be tappable before the season data behind it has arrived.
