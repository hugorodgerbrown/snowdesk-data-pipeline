{% load i18n l10n %} {% comment %} public/partials/_map_zoom_control.html — the map's zoom control (SNOW-1077). Included by _map_embed.html at the top of the bottom-left stack, and by the component library at /_components/?slug=map-zoom-control. Two things, both direct children of .map-legend once included: * The ROUNDEL, the same small roundel as the help and (i) controls beside it. Its face is the whole tile zoom the map is drawing, and its accessible name says it ("Zoom level 13"). Before SNOW-1077 this slot held a DEBUG-only that read the zoom and did nothing when pressed; it is now a public control, because two layers — the terrain filter from z12, a route's slope colours from z14 — appear only past a zoom the map never stated, and zooming was gesture-only (WCAG 2.5.1). * The FLYOUT it opens, into the crook between the stack and the date row where the legend card opens: − and + (44 px targets), a scale across the map's zoom range with a marker at the camera, a tick for each zoom-gated layer that is on, and one row per tick naming the layer. Under DEBUG it also prints the camera zoom to two decimals — the figure the old readout gave developers working on the download bands. static/js/map_zoom_control.js fills all of it from the map; the zoom gates come from window.pwaZoomGates (static/js/map.js). Every value below is empty on /map/ and set only by the component library's variants. Context (all optional): * zoom_face — int; the roundel's face (the map never goes below z4, so 0 means unset). * zoom_open — bool; render the flyout open. * zoom_marker_pct — float 0..100; the camera marker's position. * zoom_ticks — list of {key, label, zoom, pct, reached}. * zoom_out_disabled — bool; − at the minimum zoom. * zoom_in_disabled — bool; + at the maximum zoom. * zoom_camera_visible — bool; render the DEBUG camera line. * zoom_camera — str; that line's text. {% endcomment %}
