{% load i18n %} {% comment %} public/partials/_map_help_mode.html — help mode on the map (SNOW-1119). The "?" roundel used to start the tour. It now turns on help mode: every control on the map gets its name beside it, a bar says "Tap anything to see what it does" (with the tour one tap away), and a tap on a control shows what it does instead of doing it. Opening a sheet in help mode — tapping a region, a resort or saved pin, a weather symbol or a route — numbers its parts and keys them in a card. Two layers, deliberately separate: the map SURFACE (the controls, one card each) and each OVERLAY (a sheet, one guide each). Everything a reader sees is rendered here, so {% trans %} reaches every string; static/js/map_help_mode.js only reads it, positions it and wires it. Included from map.html, after the sheets it describes. What the JS reads: #map-help-controls one
  • per control: data-control is its selector, data-label the name drawn beside it, data-topic the /help/ topic its card links to, data-open the label of the card's button that leaves help mode and presses the control. The
  • 's text is the card's copy. A control not on screen gets no label. [data-sheet-guide] one guide per sheet: data-sheet is the sheet's selector (open when it is not hidden), data-topic and data-more the /help/ link under the key. Each key row's data-anchor is a selector inside the sheet for its badge; a row whose part is not on screen (scrolled away, or absent that day) keeps its number in the key and loses its badge. {% endcomment %} {% url "public:help" as help_url %}
