Nothing new was needed to make the unfocused state legible: the "no-region" state below had survived in the machine after the CSS took over the hiding, and it is now what shows. map.js's mapDownloadControlInit drives data-download-state (no-region/idle/busy/done/error/disabled/offline) and rewrites the title/aria-label to match — the done state is probed from real pinned-cache contents (every per-area bucket, unioned — SNOW-586), never a stored flag. "no-region" covers both the nothing-selected case and the focused-but-uncomputed one (properties.download is null): in both there is no basemap to fetch, which is what the label says. {% endcomment %}
