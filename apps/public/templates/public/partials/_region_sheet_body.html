Rendered by ``apps.public.region_sheet.region_sheet_partial`` and swapped by ``static/js/map_region_sheet.js`` into ``#region-sheet``, an ``includes/_overlay_sheet.html`` that declares the detents peek, half and full. One fragment serves all three, ordered so that each detent shows the next part of it: 1. PEEK (``data-sheet-peek``, which is where map_sheet.js measures the peek height to; its own partial, ``_region_sheet_peek.html``, because the surface renders it a second time, empty, for the page to fill before this body arrives) — the header ROW: the danger tile, the region's name, the pin and download controls and the ×; then where the region is, the breadcrumb. The day's full-width "Data from " row follows just below the peek (SNOW-1234 swapped the two; Hugo, 21 Oct, had taken the code, level and area out of the header). The name truncates rather than wraps, because a peek that grows a line for a long name stops being a peek (Hugo's review, 16 Oct). The header is also ``data-sheet-drag``, so the reader can drag the sheet by it as well as by the handle; its buttons keep their own press. 2. HALF and FULL — the day's date row, then the region's bulletin for the day: the bulletin page's own body, ``public/partials/_region_body.html`` (SNOW-1164). On a phone the sheet at full height covers the screen, so the sheet IS the page rather than a summary with a link on to it. FULL only when there is a bulletin for the day: the body's ``data-sheet-detents`` drops it otherwise. Last, the resorts in the region, which are map objects and so the sheet's alone. Each is a link to its resort page that, on the map, opens the resort's own sheet instead (SNOW-1161, map_region_sheet.js). THE PIN AND DOWNLOAD BUTTONS ARE PROXIES. Each one presses the roundel of the same name in the ribbon header (``#map-region-pin-control``, ``#map-download-control``), and map_region_sheet.js copies that roundel's state onto it. The roundels stay the one owner of each verb, so the sheet's star and the header's star are the same fact and cannot disagree. The labels rendered here are what shows before the first copy. Context: region — MicroRegion, with subregion__major select_related. day_rating — RegionDayRating for target_date, or None. level_label — The danger level's name ("Considerable"), or "". target_date — The day the map is showing. country_name — "Switzerland" and so on. covered — Whether any provider ever rates this region. provider_name — The provider that does not publish here, for the uncovered line. resorts — Resort rows in the region, possibly empty. terrain_switch, terrain_key — Whether to draw the problem-terrain switch, and the levels its key lists (SNOW-979, ``_region_sheet_terrain.html``). The switch turns on the "Highlight problem terrain" layer (SNOW-1194). bulletin, panel, … — The body's context, from ``apps.public.views.build_bulletin_body``; ``in_map`` True. {% endcomment %}
