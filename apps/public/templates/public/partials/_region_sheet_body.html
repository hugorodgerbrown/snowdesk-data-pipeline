{% load i18n components snowdesk_time %} {% comment %} public/partials/_region_sheet_body.html — what a tapped region's phone sheet says (SNOW-1098). Rendered by ``apps.public.region_sheet.region_sheet_partial`` and swapped by ``static/js/map_region_sheet.js`` into ``#region-sheet``, an ``includes/_overlay_sheet.html`` that declares the detents peek, half and full. One fragment serves all three, ordered so that each detent shows the next part of it: 1. PEEK (``data-sheet-peek``, which is where map_sheet.js measures the peek height to) — the danger tile, the region's name, the level and the date, the pin and download controls and the ×. The header is also ``data-sheet-drag``, so the reader can drag the sheet by it as well as by the handle; its buttons keep their own press. 2. HALF — where the region is, the day's avalanche problems (the bulletin page's own cards, ``public/_rating_block.html``) and the resorts in the region, each a link to its resort page. 3. FULL — the bulletin link. The sheet links to the bulletin rather than re-rendering it, because the bulletin page is the full-fidelity render. THE PIN AND DOWNLOAD BUTTONS ARE PROXIES. Each one presses the roundel of the same name in the ribbon header (``#map-region-pin-control``, ``#map-download-control``), and map_region_sheet.js copies that roundel's state onto it. The roundels stay the one owner of each verb, so the sheet's star and the header's star are the same fact and cannot disagree. The labels rendered here are what shows before the first copy. Context: region — MicroRegion, with subregion__major select_related. day_rating — RegionDayRating for target_date, or None. level_label — The danger level's name ("Considerable"), or "". target_date — The day the map is showing. bulletin_url — The bulletin page for that day. country_name — "Switzerland" and so on. covered — Whether any provider ever rates this region. provider_name — The provider that does not publish here, for the uncovered line. problem_cards — The bulletin's problem cards, possibly empty. resorts — Resort rows in the region, possibly empty. {% endcomment %}
