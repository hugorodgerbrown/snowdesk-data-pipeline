A region download used to start only from the region sheet, which Terrain mode takes off the map with the regions; this is the way in that works in both modes. A tap hides the sheet and opens the pick task (static/js/map_region_pick.js), handled by map_downloads_manager.js's delegated click listener, which refuses it offline and signed out exactly as it refuses the custom area.
