{% load i18n %} {% comment %} public/partials/_map_layers_switch_row.html — one on/off row of the map's layers menu (SNOW-1266): a layer with nothing to choose but whether it is drawn. The whole row is the control — one menuitemcheckbox button carrying the layer's icon, its name and a switch drawn at the right edge (includes/_switch_track.html, which reads this button's aria-checked). It is a `.basemap-menu-item--overlay` exactly as the row it replaced was, so map.js seeds it from the persisted state, map_basemap_picker.js toggles it through the overlay's bridge or storage key, and map_layer_sync_status.js finds its sync dot. A row that HAS options is not this partial: it splits into an opener and a separate switch (_map_embed.html). Every row renders unchecked; map.js writes the real state before the menu can open. Parameters (passed via {% include … with … only %}): key (string) — the row's data-overlay-key. label (string) — the layer's translated name. icon (string) — the house icon to lead with: includes/_icon_.html. sync (bool, optional) — carry a sync-status dot. Off for downloaded areas, whose list is local and so always available offline. weather (bool, optional) — carry the weather row's second line, which map_weather_window.js fills on a day outside the forecast window. zoom_gate (string, optional) — the layer's key in window.pwaZoomGates, for a layer drawn only past a zoom (SNOW-1280): the row gets the zoom suffix and the "Zoom in to view" line (_map_layers_zoom_label.html), driven by map_layers_zoom_gates.js. {% endcomment %}
