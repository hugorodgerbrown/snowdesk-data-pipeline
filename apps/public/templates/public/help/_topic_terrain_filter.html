{% blocktrans trimmed %} The terrain filter highlights ground by the three things a bulletin uses to say where the danger is: the aspect a slope faces, how steep it is, and how high it is. Choose any of the eight aspects, a slope range from 30 degrees upward, and if you like a band of elevation, and the map tints the ground that matches in blue. Ground that does not match is left as it is. Open it from the layers menu’s “Terrain filter…” row; while it is on, a chip at the top of the map says what it is set to, and a tap on the chip opens it again. {% endblocktrans %}

{% blocktrans trimmed %} The filter shows from zoom level 12, roughly a valley across the screen; zoom out further and the sheet asks you to zoom in. {% endblocktrans %}

{% blocktrans trimmed %} Hatched means no data. Where the terrain data has nothing, the ground is hatched in grey, so an untinted slope always means “does not match” and never “not surveyed”. Level ground, such as a lake, faces no direction and never matches. {% endblocktrans %}

{% trans "What it cannot tell you" %}

{% blocktrans trimmed %} It describes the terrain and nothing else. It says nothing about the snowpack, the weather or the day’s danger rating, and a tinted slope is not one that will avalanche, any more than an untinted one is safe. {% endblocktrans %}

{% blocktrans trimmed %} It does not show runout zones. An avalanche released on a matching slope can run far onto ground that does not match — a gentle valley floor below a steep north face is untinted and still in the path. {% endblocktrans %}

{% blocktrans trimmed %} Treat it as a way of finding the slopes a bulletin is talking about, never as a verdict on whether to ski them. {% endblocktrans %}

{% blocktrans trimmed %} It covers Switzerland only. The terrain data is swisstopo’s swissALTI3D elevation model, and outside Switzerland the filter has nothing to show. {% endblocktrans %}
