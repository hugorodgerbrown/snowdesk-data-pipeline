{% blocktrans trimmed %} Snowdesk can be installed as an app on your phone or computer. Look for an "Install" or "Add to Home Screen" option in your browser's address bar or share menu — once installed, it opens in its own window without any browser chrome. {% endblocktrans %}

{% blocktrans trimmed %} Pages you have already visited load instantly on repeat visits, and keep working with no connection, because both the app and the data behind those pages are kept on your device. Snowdesk always asks the network first and only falls back to what it holds. {% endblocktrans %}

{% blocktrans trimmed %} That means a rating you see offline is the last one this device fetched, not necessarily the one in force. Whenever the connection is failing — or has failed often enough that Snowdesk has stopped trying and is serving stored data only — a banner across the top says so and says how long ago this device last reached the server. Check it before you trust a rating, and reload once you have signal. {% endblocktrans %}

{% blocktrans trimmed %} You can also stop Snowdesk using the network yourself, with the signal button at the top of every page. Turn it off before you lose coverage, or to spare a metered or roaming connection, and the app runs from what it has already stored. It stays off until you turn it back on — Snowdesk will not quietly reconnect — and the banner stays up meanwhile so you can see how old the stored data is. {% endblocktrans %}

{% blocktrans trimmed %} The background map is the exception: it is stored only for the areas you download yourself — see "Offline downloads" above. {% endblocktrans %}
