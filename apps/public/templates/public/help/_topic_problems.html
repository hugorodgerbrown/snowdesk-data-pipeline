{% blocktrans trimmed %} The danger rating says how dangerous the day is. The avalanche problems say why, and where. Each one is a card like the example above, and a bulletin usually carries one to three of them. {% endblocktrans %}

{% blocktrans trimmed %} The icon and title name the problem — fresh wind slab, a persistent weak layer buried in the snowpack, wet snow, gliding snow, new snow or cornices. Each behaves differently and asks for a different response, which is why the bulletin names them rather than giving you a number alone. {% endblocktrans %}

{% blocktrans trimmed %} Below the title, the compass rose and the elevation glyph say where the problem lives: which slope aspects it has formed on, and above or below which height. A problem on north-through-south-east aspects above 2200 metres is not a problem on a sunny south-west slope at the valley floor, and the card is telling you where to expect it. {% endblocktrans %}

{% blocktrans trimmed %} The comment underneath is the forecaster's own words, shown as they wrote them. It is the part that says what will release the problem and how it will behave, and it is worth reading in full — Snowdesk never summarises it away. {% endblocktrans %}
