The third tier of the map's legend (3 Nov 2026): the (i) card opens on a key for what the current view draws, its second page lists every key short, and its "Every key, described in full" link lands here. So this is the long form of each key, in the card's order — the day's layers, then the ones every day shares. /help/ loads output.css alone, never static/css/map.css, so the swatches are token utilities (bg-eaws-*, bg-slope-*, bg-rest-*), not the card's .map-legend-swatch classes. {% endcomment %} {% load i18n %}

{% blocktrans trimmed %} The (i) button at the bottom left of the map opens its key. It lists only what is drawn where you are looking: pan to another valley or zoom out, and the key follows. Its "All keys & sources" page lists everything the map can show, and who the data is from. {% endblocktrans %}

{% trans "Danger level" %}

{% blocktrans trimmed %} Each avalanche region is coloured by the bulletin's danger level for the day the map shows, on the European five-level scale. Grey is a region with no rating that day. Zoomed in, the colour gives way to a band just inside each region's edge and its level, so the ground stays readable. {% endblocktrans %}

  • {% trans "Low (1)" %}
  • {% trans "Moderate (2)" %}
  • {% trans "Considerable (3)" %}
  • {% trans "High (4)" %}
  • {% trans "Very high (5)" %}

{% trans "Problem slopes" %}

{% blocktrans trimmed %} With "Sync with map terrain" on, the steep ground an avalanche problem in the bulletin describes is painted in that problem's danger colour, from zoom 12 in Switzerland. The colours are the danger scale's, so the key does not repeat them. Grey is other steep ground over 30° that no problem describes, which is not the same as safe; hatching is ground the terrain data does not cover. {% endblocktrans %}

{% trans "Field reports" %}

{% blocktrans trimmed %} Reports from people out on the snow, one pin each, by what they saw: warning signs, the snow surface, or the trail. A filled pin was reported on the map's day; a ring, in the three days before. {% endblocktrans %}

{% trans "Weather" %}

{% blocktrans trimmed %} From zoom 7, each weather point shows the map's day as a symbol and a temperature, and under them the point's own height, which is where the forecast is for. Tap one for the day hour by hour. {% endblocktrans %}

{% trans "Steep terrain" %}

{% blocktrans trimmed %} The ground's own slope, from zoom 11 in Switzerland. By slope, each class has its colour; with one tint, only the ground your filter matches is painted. Hatching is ground with no terrain data. {% endblocktrans %}

  • {% trans "30–35°" %}
  • {% trans "35–40°" %}
  • {% trans "40–45°" %}
  • {% trans "45–50°" %}
  • {% trans "Over 50°" %}

{% trans "Ski tours" %}

{% blocktrans trimmed %} The Swiss Alpine Club's ski tours, from zoom 9: deep blue on the way up, sky blue on the way down, never dashed. A dark dot is a summit a tour goes to and a ring a hut. Tap a line to open the tour. {% endblocktrans %}

{% trans "Wildlife rest zones" %}

{% blocktrans trimmed %} Areas set aside for wildlife in winter, from the Federal Office for the Environment. Red is closed by law; amber is a closure FOEN advises. A zone is drawn strongly when the map's day is inside its protected period, and faintly when it is out of season, so you can still see it when planning another day. {% endblocktrans %}

  • {% trans "Closed by law" %}
  • {% trans "Advised" %}
  • {% trans "Closed by law, out of season" %}
  • {% trans "Advised, out of season" %}

{% trans "Your routes" %}

{% blocktrans trimmed %} A saved route is drawn as its legs, each running between two transitions and numbered along the track: dashed where it climbs, solid where it descends. A route whose legs are not worked out yet is one plain line. Close in, from zoom 14, the line is coloured by the slope of the ground under it instead. A dot marks the start and a chequered flag the finish. Press a leg on the route's profile to highlight it, or tap the line to read one point. {% endblocktrans %}

{% trans "Pins" %}

{% blocktrans trimmed %} A dark dot is a ski resort and a blue dot a resort you have pinned. A blue star is a place you dropped a pin on. {% endblocktrans %}

{% trans "Boundaries" %}

{% blocktrans trimmed %} The avalanche regions at the levels the layers menu turns on: a heavy dark red line round a major region, a blue one round a minor region, a thin grey one round each micro region, the smallest area a bulletin rates. A dashed outline is a region no provider has ever rated. On a day's map, a green outline joins the regions one bulletin covers together. {% endblocktrans %}

{% trans "Your position" %}

{% blocktrans trimmed %} Once you ask the map to find you, a blue dot with a white ring is where your device says you are. Tap it for what is there. {% endblocktrans %}

{% trans "Downloaded maps" %}

{% blocktrans trimmed %} While you are offline, or with the overlay on, hatching marks the ground downloaded for the basemap you are using, and an outline ground downloaded for another one. Zoomed out, everywhere shows the low-detail overview map, so zoom in to check an area is really downloaded. {% endblocktrans %}
