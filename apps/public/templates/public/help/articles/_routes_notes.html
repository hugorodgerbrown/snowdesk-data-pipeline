  • {% blocktrans trimmed %} Routes are private. Nothing is published, and nobody sees one unless you send them its link. {% endblocktrans %}
  • {% blocktrans trimmed %} Once loaded on a device, the lines stay on the map without a connection. The list in the panel needs one, and says so. {% endblocktrans %}
  • {% blocktrans trimmed %} There is a limit on the size of one file and on how many routes an account keeps. The panel tells you when you reach either. {% endblocktrans %}
  • {% blocktrans trimmed %} A very long track is thinned before it is stored. Its shape, distance and profile are kept. {% endblocktrans %}
  • {% blocktrans trimmed %} The file you exported is not always the file you want on the map. The panel points you at a free browser tool for cropping or splitting a track first. {% endblocktrans %}
