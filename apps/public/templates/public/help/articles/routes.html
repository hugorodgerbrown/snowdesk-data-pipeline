{% translate "What routes are" as t_what %} {% include "includes/_eyebrow.html" with text=t_what class_extra="mb-4" only %}

{% blocktrans trimmed %} A route is a track you have uploaded — a .gpx file of the kind a GPS watch, a planning tool or a touring app exports. Snowdesk draws it on the map over the same regions and danger ratings you already read there, so you can see a line you plan to ski against the conditions forecast for it. {% endblocktrans %}

{% blocktrans trimmed %} Routes are yours. Nothing is published, nothing appears on anyone else's map, and the only way another person sees one is that you send them a link. {% endblocktrans %}

{% translate "Where to find them" as t_where %} {% include "includes/_eyebrow.html" with text=t_where class_extra="mb-4" only %}

{% blocktrans trimmed %} There are two places, and they do different jobs. {% endblocktrans %}

{% blocktrans trimmed %} On the map, the routes button sits in the column of round buttons down the right-hand side. It opens the Routes panel: everything you have uploaded, an "Add a route" button, and a "Display on the map" switch at the foot that draws them all. {% endblocktrans %}

{% blocktrans trimmed %} In the menu, "Routes" opens a full page of the same list, which is easier to work through when you have a lot of them. You can rename, remove and share from there, but not upload — adding a route is done from the map panel. {% endblocktrans %}

{% translate "How they work" as t_how %} {% include "includes/_eyebrow.html" with text=t_how class_extra="mb-4" only %}

{% blocktrans trimmed %} You need to be signed in to save a route. {% endblocktrans %}

{% include "includes/_help_steps.html" with body_template="public/help/articles/_routes_steps.html" %}

{% blocktrans trimmed %} Tapping a line on the map opens that route's own popup: its name, the same figures, and an elevation profile of the whole track. The profile is drawn from the heights in your file, so a track recorded without them shows none rather than a flat line. {% endblocktrans %}

{% blocktrans trimmed %} Each row in the panel carries a pencil to rename the route in place and a control to remove it. The file you exported is not always the file you want on the map — the panel points you at a free browser tool for cropping or splitting a track before you upload it. {% endblocktrans %}

{% translate "Sharing one route" as t_sharing %} {% include "includes/_eyebrow.html" with text=t_sharing class_extra="mb-4" only %}

{% blocktrans trimmed %} The Share control on a route's row gives you a link to send someone. Whoever opens it sees that one route drawn on their map with a button to save it. They can open the link before they have signed in, and it will still be waiting once they have. {% endblocktrans %}

{% blocktrans trimmed %} Saving takes a copy. Theirs is theirs to rename or remove, yours is untouched, and the two never affect each other afterwards. The link keeps working for a few weeks, and stops working straight away if you remove the route it points at. {% endblocktrans %}

{% translate "What it won't do" as t_limits %} {% include "includes/_eyebrow.html" with text=t_limits class_extra="mb-4" only %}

{% blocktrans trimmed %} Once your routes have loaded on a device, the lines stay on the map with no connection. The list inside the panel needs one, and says so rather than pretending you have no routes. {% endblocktrans %}

{% blocktrans trimmed %} Uploading needs a connection, and so do renaming and removing — unlike a field observation, those actions are not queued for later. {% endblocktrans %}

{% blocktrans trimmed %} There is a limit on the size of a single file and on how many routes one account can keep; the panel tells you when you reach either. A very long track is thinned before it is stored, which keeps it quick to draw and leaves its shape, distance and profile intact. {% endblocktrans %}
