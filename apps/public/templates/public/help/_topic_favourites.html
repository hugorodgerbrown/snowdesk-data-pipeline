{% blocktrans trimmed %} Favourites let you pin specific spots — a resort, a trailhead, a favourite line — directly on the map. Sign in, then use "Add a favourite pin" to drop a pin at any point. {% endblocktrans %}

{% blocktrans trimmed %} Each favourite carries its own multi-day point forecast — temperature, snowfall, and conditions for that exact location — alongside the region's avalanche bulletin, so you can see both together. {% endblocktrans %}
