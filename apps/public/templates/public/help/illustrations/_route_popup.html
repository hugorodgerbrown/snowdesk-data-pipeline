{% comment %} public/help/illustrations/_route_popup.html — the route popup, for the Routes article. THE ONE ILLUSTRATION THAT IS NOT A REAL PARTIAL, and why. The popup a tap on a route opens is assembled in JavaScript — map.js's ``activateRoute`` builds the title, the figures line and the caption, and static/js/elevation_profile_core.js's ``createProfileSvg`` draws the chart — so there is no server template to include. This file mirrors that markup, class for class and attribute for attribute, and takes its path data from the Python port of the chart's projection in apps.public.component_previews. Change one and change the other. Not the popup's chrome (the box, its arrow, its close X): those are MapLibre's and static/css/map.css's, which a help page does not load.
