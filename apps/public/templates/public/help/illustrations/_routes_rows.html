Nothing can post to it: the wrapper this sits in is inert. ``csrf_token="NOTPROVIDED"`` is Django's own sentinel for "no token here" — what RequestContext carries when the CSRF middleware is not in play — and the token tag renders nothing for it, without the warning an absent value logs. The real value is a lazy read of the session (CSRF_USE_SESSIONS), and that read is a query; a help page issues none, and a decoration has no use for a token.
