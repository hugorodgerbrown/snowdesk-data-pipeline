{% blocktrans trimmed %} A region’s panel on the map has a “Show problem terrain on the map” switch above its bulletin. Switched on, it paints the region’s ground of 30 degrees and steeper by what that day’s bulletin says about it: where a problem’s aspects and heights take in a slope, the slope is painted in the colour of that problem’s danger level. Where two problems overlap, the higher level wins, and a day with a morning and an afternoon bulletin shows the worse of the two. It paints the region whose panel is open, and stops when you close the panel; the switch remembers whether you left it on. {% endblocktrans %}

{% blocktrans trimmed %} Grey hatching is not “safe”. Steep ground that no problem describes is hatched in warm grey rather than left blank. A bulletin’s aspects and heights mark where a problem is most pronounced, not a line beyond which it stops, so much of the steep ground on any day falls outside them and can still slide. {% endblocktrans %}

{% blocktrans trimmed %} Some problems cannot be placed slope by slope. One bounded by the treeline has no height we can test, and one whose aspects come only from the bulletin’s text cannot be read as precisely as the structured ones. Ground such a problem may describe is painted a flat grey, “described, can’t be placed”, rather than as a match or a miss. {% endblocktrans %}

{% blocktrans trimmed %} The terrain shows from zoom level 12, roughly a valley across the screen; switching it on further out takes the map there. Ground the terrain data has nothing for is hatched in slate, the other way from the grey. {% endblocktrans %}

{% trans "What it cannot tell you" %}

{% blocktrans trimmed %} It does not show runout zones. An avalanche released on painted ground can run far onto gentle ground below, which is never painted. {% endblocktrans %}

{% blocktrans trimmed %} It shows where the bulletin describes its problems, not a hazard map and never a verdict on whether to ski a slope. Read the bulletin under the switch; the layer is a way of finding the slopes it is talking about. {% endblocktrans %}

{% blocktrans trimmed %} It covers Switzerland only, because the terrain data is swisstopo’s swissALTI3D elevation model. A region elsewhere has no switch. {% endblocktrans %}
