Documents the layers menu (#basemap-menu in public/partials/_map_embed.html) group by group, in the order the menu itself renders them: Bulletins, Boundaries, Locations, Conditions, Terrain, Base map. Two of those groups have a panel of their own on this page — Weather and Slope angle — so the rows here get a sentence and a pointer rather than a second copy of the detail. The user-generated overlays (favourites, field observations, routes) are deliberately NOT described here: SNOW-658 moved each one's toggle out of this menu and into the panel its own roundel opens, and the last paragraph says so, because a reader who remembers the old menu rows will otherwise go looking for them. {% endcomment %} {% load i18n %}

{% blocktrans trimmed %} The stacked-squares button on the right of the map opens the layers menu — one list controlling everything the map draws, grouped by what each row is. A row you switch on stays on the next time you open Snowdesk on this device. {% endblocktrans %}

{% trans "Bulletins" %}

{% blocktrans trimmed %} One row per provider — SLF (CH), Météo-France (FR) and ALBINA (AT, IT) — each covering the countries that provider publishes for. Switching one off takes its bulletins off the map, which is the way to look at one country's picture on its own. Switzerland is on to start with. {% endblocktrans %}

{% blocktrans trimmed %} How strongly the danger colour paints is a separate control: the half-filled square below the layers button steps the shading from off to full, so you can read the terrain underneath without losing the bulletin altogether. {% endblocktrans %}

{% trans "Boundaries" %}

{% blocktrans trimmed %} Outlines of the European avalanche regions at three scales: Major (EAWS Level 1), Minor (EAWS L2) and Micro (EAWS L4). Micro is the level bulletins are issued at and is drawn by default; the two coarser outlines help you place a small region inside the wider area it belongs to. {% endblocktrans %}

{% trans "Locations" %}

{% blocktrans trimmed %} Resorts draws a pin at every ski resort Snowdesk knows about. Tapping one opens a short popup — the resort's name, the region it sits in, a link to that region's bulletin, and a star to save it to your favourites. {% endblocktrans %}

{% trans "Conditions" %}

{% blocktrans trimmed %} Weather draws a condition symbol and the day's high temperature at every place Snowdesk holds, with the height that reading is for beneath it. It follows the timeline like everything else on the map, and it has rules of its own worth knowing about — read "Weather on the map" below. {% endblocktrans %}

{% trans "Terrain" %}

{% blocktrans trimmed %} Slope angle shades the ground by steepness. It is the one layer with real limits on what it can tell you, so read "Slope angle" below before you rely on a shading. {% endblocktrans %}

{% trans "Base map" %}

{% blocktrans trimmed %} The map underneath everything else. OpenFreeMap covers the whole area; the national mapping-agency maps — Swisstopo (CH), IGN (FR) and basemap.at (AT) — carry far more detail for their own country and are blank outside it, so switching to one is a choice to look closely at one place. {% endblocktrans %}

{% trans "The dot on each row" %}

{% blocktrans trimmed %} Every row carries a small dot saying whether that layer is held on this device: green for available offline, grey for not stored yet, and a pulse while it is being fetched. It is there so you can check what will still work before you lose signal. {% endblocktrans %}

{% blocktrans trimmed %} A row is sometimes switched off with a reason attached — the slope layer outside the area it covers, or any layer that has never been loaded while you were online. The note on the row says which. {% endblocktrans %}

{% blocktrans trimmed %} Your own pins, reports and routes are not in this menu. Each has its own button on the right of the map, and the "Display on the map" switch inside that button's panel is what puts it on the map. {% endblocktrans %}
