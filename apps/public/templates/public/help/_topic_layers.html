{% blocktrans trimmed %} The stacked-squares button on the right of the map opens the layers menu — one list controlling everything the map draws, grouped by what each row is. A row you switch on stays on the next time you open Snowdesk on this device. {% endblocktrans %}

{% trans "Places" %}

{% blocktrans trimmed %} Resorts draws a pin at every ski resort Snowdesk knows about. Tapping one opens a short popup — the resort's name, the region it sits in, a link to that region's bulletin, and a star to save it to your favourites. {% endblocktrans %}

{% blocktrans trimmed %} Favourites draws your own saved places, and Routes draws every track you have uploaded. Both need an account: tapping one while you are signed out offers you the way in rather than switching on a layer with nothing in it. {% endblocktrans %}

{% trans "Conditions" %}

{% blocktrans trimmed %} One row per bulletin provider — SLF (CH), Météo-France (FR) and ALBINA (AT, IT) — each covering the countries that provider publishes for. Switching one off takes its bulletins off the map, which is the way to look at one country's picture on its own. Switzerland is on to start with. {% endblocktrans %}

{% blocktrans trimmed %} How strongly the danger colour paints is a separate control: the half-filled square below the layers button steps the shading from off to full, so you can read the terrain underneath without losing the bulletin altogether. {% endblocktrans %}

{% blocktrans trimmed %} Weather draws a condition symbol and the day's high temperature at every place Snowdesk holds, with the height that reading is for beneath it. It follows the timeline like everything else on the map, and it has rules of its own worth knowing about — read "Weather on the map" below. {% endblocktrans %}

{% blocktrans trimmed %} Field observations draws what other people have reported from the ground, fading as each report ages. It is public, so it works whether or not you are signed in. {% endblocktrans %}

{% trans "Boundaries" %}

{% blocktrans trimmed %} Outlines of the European avalanche regions at three scales: Major (EAWS Level 1), Minor (EAWS L2) and Micro (EAWS L4). Micro is the level bulletins are issued at and is drawn by default; the two coarser outlines help you place a small region inside the wider area it belongs to. They follow the base map rather than the Bulletins rows: on a national base map you see that country's regions, and on OpenFreeMap you see all of them. {% endblocktrans %}

{% trans "Basemap" %}

{% blocktrans trimmed %} The map underneath everything else, and the only section where you pick one rather than switching several on. OpenFreeMap covers the whole area; the national mapping-agency maps — Swisstopo (CH), IGN (FR) and basemap.at (AT) — carry far more detail for their own country and are blank outside it, so switching to one is a choice to look closely at one place. {% endblocktrans %}

{% blocktrans trimmed %} Two things are drawn on top of whichever one you chose, which is why they sit under this heading. "Display slope angles" shades the ground by steepness — the one layer with real limits on what it can tell you, so read "Slope angle" below before you rely on a shading. {% endblocktrans %}

{% blocktrans trimmed %} "Display downloaded areas" shades the ground you already hold on this device, so you can see the edges of your own coverage before you set off. Left alone it switches itself on whenever you are offline, which is when the answer matters. {% endblocktrans %}

{% trans "The dot on each row" %}

{% blocktrans trimmed %} Most rows carry a small dot saying whether that layer is held on this device: green for available offline, grey for not stored yet, and a pulse while it is being fetched. Green means the data is on the device right now, checked rather than assumed, so you can see what will still work before you lose signal. Two rows have no dot, because neither could answer honestly: slope angles come from someone else's map server, and your downloaded areas are on this device by definition. {% endblocktrans %}

{% blocktrans trimmed %} A row is sometimes switched off with a reason attached — the slope layer outside the area it covers, or any layer that has never been loaded while you were online. The note on the row says which. {% endblocktrans %}

{% blocktrans trimmed %} Each heading opens and closes, and remembers which way you left it. The line under a heading says what is on inside it without you having to open it, and the count at the top of the menu says how many layers are on altogether. {% endblocktrans %}
