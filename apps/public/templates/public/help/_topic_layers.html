Documents the layers menu (#basemap-menu in public/partials/_map_embed.html) row by row, in the order the menu renders them: "Reference data" (bulletins, steep terrain, weather, resorts, boundaries, basemap), then "Your data" (favourites, routes, field observations, downloaded areas). {% blocktrans trimmed %} The stacked-squares button on the right of the map opens the layers menu — one list of everything the map can draw, with a switch for each. A layer you switch on stays on the next time you open Snowdesk on this device. {% endblocktrans %}

{% blocktrans trimmed %} The switch on the right of a row says whether that layer is drawn. A row with an arrow also has options: tap its name to see them, and the back arrow to return. The line under a row's name says what its options are set to, and the count at the top of the menu says how many layers are on altogether. {% endblocktrans %}

{% trans "Reference data" %}

{% blocktrans trimmed %} Avalanche bulletins paints each region in its danger colour. Its options have one row per bulletin provider — SLF (CH), Météo-France (FR) and ALBINA (AT, IT) — each covering the countries that provider publishes for. Switching one off takes its bulletins off the map, which is the way to look at one country's picture on its own. Switzerland is on to start with. {% endblocktrans %}

{% blocktrans trimmed %} Under the providers, "Bulletin opacity" sets how strongly the danger colour paints: four steps up to full, so you can read the terrain underneath without losing the bulletin altogether. Switching the bulletins off and on again brings back the strength you left them at. "Highlight problem terrain" is there too: it paints the slopes the day's bulletin describes, from zoom 12. {% endblocktrans %}

{% blocktrans trimmed %} Steep terrain highlights ground by aspect, slope range and, if you like, a band of elevation. Tap its name to open the panel where you choose them. That panel also carries the "Highlight problem terrain" switch, so the bulletin's own colouring can be turned on or off from the same place. Read "Terrain filter" below for what it does not tell you. {% endblocktrans %}

{% blocktrans trimmed %} The same panel holds the slope layer, which shades the ground by steepness: choose “By slope”. It is the layer with the most real limits on what it can tell you, so read "Slope angle" below before you rely on a shading. {% endblocktrans %}

{% blocktrans trimmed %} Weather draws a condition symbol and the day's high temperature at every place Snowdesk holds, with the height that reading is for beneath it. It follows the timeline like everything else on the map, and it has rules of its own worth knowing about — read "Weather on the map" below. {% endblocktrans %}

{% blocktrans trimmed %} Resorts draws a pin at every ski resort Snowdesk knows about. Tapping one opens a short popup — the resort's name, the region it sits in, a link to that region's bulletin, and a star to save it to your favourites. {% endblocktrans %}

{% blocktrans trimmed %} Boundaries outlines the European avalanche regions at three scales: Major (EAWS Level 1), Minor (EAWS L2) and Micro (EAWS L4). Micro is the level bulletins are issued at and is drawn by default; the two coarser outlines help you place a small region inside the wider area it belongs to. They follow the base map rather than the bulletin providers: on a national base map you see that country's regions, and on OpenFreeMap you see all of them. {% endblocktrans %}

{% blocktrans trimmed %} Basemap is the map underneath everything else, and the one row with no switch: there is always one, and you pick which. OpenFreeMap covers the whole area; the national mapping-agency maps — Swisstopo (CH), IGN (FR) and basemap.at (AT) — carry far more detail for their own country and are blank outside it, so switching to one is a choice to look closely at one place. {% endblocktrans %}

{% trans "Your data" %}

{% blocktrans trimmed %} Favourites draws your own saved places, and Routes draws every track you have uploaded. Both need an account: tapping one while you are signed out offers you the way in rather than switching on a layer with nothing in it. Each panel has its own "Show on the map" switch, which is the same setting as the switch here. {% endblocktrans %}

{% blocktrans trimmed %} Field observations draws what people have reported from the ground, fading as each report ages. It is public, so it works whether or not you are signed in. {% endblocktrans %}

{% blocktrans trimmed %} Downloaded areas shades the ground you already hold on this device, so you can see the edges of your own coverage before you set off. Left alone it switches itself on whenever you are offline, which is when the answer matters. {% endblocktrans %}

{% trans "The dot on each row" %}

{% blocktrans trimmed %} Most rows carry a small dot saying whether that layer is held on this device: green for available offline, grey for not stored yet, and a pulse while it is being fetched. Green means the data is on the device right now, checked rather than assumed, so you can see what will still work before you lose signal. Two rows have no dot, because neither could answer honestly: steep terrain draws from tiles kept as you look at the map, so what is held depends on where you have been, and your downloaded areas are on this device by definition. {% endblocktrans %}

{% blocktrans trimmed %} A row is sometimes switched off with a reason attached — a layer that has never been loaded while you were online, for instance. The note on the row says why. {% endblocktrans %}
