{% blocktrans trimmed %} A Weather overlay on the map shows a condition symbol and the day's forecast high temperature at every resort, so you can see the weather picture alongside the avalanche danger without leaving the map. {% endblocktrans %}

{% blocktrans trimmed %} Point weather only covers the next several days, and sometimes fewer than that. Scrubbing to a date outside that window disables the overlay's menu row until you scrub back to a date it has data for. {% endblocktrans %}

{% blocktrans trimmed %} Zoomed out, there are no resort symbols to draw — so the overlay switches to a coarser view instead: one symbol at the centre of each avalanche region. A region can be tens of kilometres across, and that one symbol stands for the whole of it, so read it as the region's general picture rather than as the weather at any particular spot. This coarser view covers today and recent days rather than the days ahead. Zoom in past the point where resort symbols appear and you are back to per-resort weather, with temperatures. {% endblocktrans %}

{% blocktrans trimmed %} If you're signed in, your own favourite pins get a weather symbol too — visible only to you, never to anyone else. {% endblocktrans %}
