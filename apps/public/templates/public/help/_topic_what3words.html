{% blocktrans trimmed %} Every trip has a meeting point: the spot the organiser dropped on the map when they planned it. Where we can, it is shown as a three word address — three words after a triple slash, like ///filled.count.soap. The words are not a name anyone chose. They identify one 3-metre square of ground anywhere in the world, so they say exactly what a pair of coordinates says, in something you can read down a phone. {% endblocktrans %}

{% blocktrans trimmed %} To find the square, type the three words into what3words or into a map app that understands them. The organiser's page and the link they send you both show the same address, so everyone on a trip is looking at the same words. {% endblocktrans %}

{% blocktrans trimmed %} When we have no address for a meeting point, the page shows its latitude and longitude instead — the same numbers it has always shown, ready to paste into a map app. The meeting point is never blank. {% endblocktrans %}
