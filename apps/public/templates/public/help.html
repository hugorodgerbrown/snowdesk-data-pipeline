{% extends "public/base.html" %} {% comment %} apps/public/templates/public/help.html — Plain-language "how it works" help page. Introduced for SNOW-456. Distinct from how_to_read_bulletin.html, which teaches the avalanche domain; this page documents the product itself — the map, favourites, field observations, the season timeline, accounts, and PWA install/offline behaviour — as a set of collapsible panels reusing includes/_collapsible_panel.html. Each panel's body copy lives in its own small content partial under apps/public/templates/public/help/. The Sync-log panel is gated on the per-user ``sync_log_visible`` waffle boolean computed by apps.public.views.help_page — a user never sees documentation for a feature they cannot use. It is the only gated panel; SNOW-724 opened the slope-angle topic to everyone. The panels are grouped under four eyebrow headings rather than running as one flat list of sixteen: "The map" alone holds eight, and a reader looking for the layers menu should not have to read past the season calendar to find it. The headings are includes/_eyebrow.html, the same section label the bulletin and account pages use. EVERY map control has a panel here, and the map's own coachmark tour (``#map-help-steps`` in public/partials/_map_embed.html) is the other half of the same job: a control added to the map needs a step there and a section here, or it ships undocumented in both places, which is how Routes and Offline downloads came to have neither. {% endcomment %} {% load i18n components %} {% block page_meta %} {% trans "Help" as page_name %} {% trans "Plain-language guide to how Snowdesk works: the map, bulletins, favourites, and more." as page_description %} {% include "includes/_page_meta.html" with title=page_name|add:" · Snowdesk" description=page_description %} {% endblock page_meta %} {% block content %}
