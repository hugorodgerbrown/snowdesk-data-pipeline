Renders every IconPartial in ``category.tokens``: one card per house stroke glyph (templates/includes/_icon_*.html), alphabetical as the registry lists them. Each card draws the glyph once per ``icon.renders`` entry (its default size, the 24px grid size, then the sizes and states its header documents) through ``include_variant``, so the partial renders exactly as a caller's ``{% include %}`` would. Below that: the glyph's name, what it means, the include line and the parameters it reads. The glyphs draw in currentColor, so they take ``text-text-1`` from the card and follow the light / dark section the panel wrapper puts them in.
