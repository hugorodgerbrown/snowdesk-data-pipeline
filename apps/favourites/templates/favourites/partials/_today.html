{% load i18n %} {% comment %} favourites/partials/_today.html — the Today panel's list (SNOW-1366). Rendered by apps.favourites.views.today and swapped into the Today panel (public/partials/_today_surface.html) by static/js/today_panel.js. Built by apps.favourites.today.build_today: one row per region the user pinned or holds a pinned resort in, in name order, and that region's pinned resorts nested under it, in name order too: never by urgency, so a place is where it was yesterday (Hugo, 2 Nov 2026). Always today, whatever day the map shows. The region row carries the danger: the region's EAWS tile for today and, under its name, how the level moved since yesterday, in words, so neither colour nor the digit carries it alone. A resort row carries no danger of its own (a resort has none, docs/decisions/a-resort-has-no-avalanche-danger.md); it carries the resort's weather. A region listed only because a resort in it is pinned says so ("not pinned"). Both are includes/_place_link_row.html, the row every place sheet uses to open its neighbours: a real link to the place's page, which on the map static/js/map_panel_trail.js opens as that place's sheet instead. The root's ``data-panel-key`` / ``data-panel-label`` are what that module names the back pill by, so the sheet a row opens offers the way back to Today. A borrowed forecast says where it is from (includes/_forecast_source.html), as docs/decisions/snowdesk-decides-where-a-forecast-is-fetched.md asks of every borrowing surface. A resort normally reads its own pin's forecast, and then the line would only repeat the resort's name, so it is shown only when the point is somewhere else.
