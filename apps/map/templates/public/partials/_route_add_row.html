Included only by public/partials/_route_add_rows.html, three times, as the three cells of one row. A button with a stroke icon beside a one-word label, the same 46px height and chrome as the panel's own add button (includes/_panel_add_button.html). The first, the least work, is the ink primary; the other two are outlined secondaries. Each button's accessible name is the full phrase ("Find a route"), which starts with the word it shows, so a screen reader and a voice command agree with what is on screen. The row was three full-width cards with a line of description each until Hugo asked for them "fit into a row" (8 Nov 2026). Parameters: hook — which way in: "find" (data-ski-tour-find, ski_tours.js), "create" (data-route-draw-start, route_draw.js) or "upload" (data-panel-add, the UGC panel). A fixed choice rather than an attribute passed in, so no template value is ever written into the tag unquoted. label — the visible one-word label. name — the accessible name, the full phrase. icon — template path of the stroke icon. emphasised — bool: the button to start from. {% endcomment %}
