{% load i18n %} {% comment %} public/partials/_route_add_rows.html — the routes panel's three ways to add a route (SNOW-1278; "Draw on the map" alone since SNOW-1256). Rendered by includes/_ugc_panel.html's ``foot_template`` IN PLACE OF the panel's own add button (``foot_replaces_add``), only while the ``route_drawing`` flag is active for the request — see public/partials/_routes_surface.html. One row of three equal buttons, ordered by how much work each takes, so the least is first and emphasised (Hugo, 28 Oct 2026). A flex row rather than a grid, so the two left for a visitor who cannot upload share it evenly. They were three full-width cards with a description each until Hugo asked for one row (8 Nov 2026): the panel is "Routes", so one word says what each does. * Find — start from an SAC tour (``data-ski-tour-find``, static/js/ski_tours.js): the panel closes, the ski-touring routes come on, and a hint says to tap a summit or a route. * Create — draw one, snapping to existing routes where there are any (``data-route-draw-start``, static/js/route_draw.js). * Upload — a GPX file: ``data-panel-add``, the hook routes.js has always opened the file picker by, and removes for a visitor who cannot upload. Finding and drawing need no account ("drawing is free, saving needs an account", 27 Oct 2026), so those two stay for an anonymous visitor; each asks them to sign in only when they press Save. All three hooks are read on the document or the sheet, because the panel body is re-cloned from its template on every open. {% endcomment %}
