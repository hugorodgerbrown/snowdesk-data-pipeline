{% comment %} Passkey conditional UI — started when the user focuses the email field, not on page load. WebAuthn credential providers (1Password, Dashlane, iCloud Keychain, the browser's own manager, …) surface their UI in response to the navigator.credentials.get() call itself, so calling it at page load pops an unsolicited passkey prompt for anyone running a third-party provider (SNOW-519). Deferring the ceremony to first focus of the email field ties it to a deliberate sign-in gesture — nothing appears on a bare page load. On successful passkey sign-in the page is reloaded; the sign_in_view then detects request.user.is_authenticated and redirects to manage. {% endcomment %} {% endblock %}
